# 동위원소 지도 검증 프롬프트 v2

Oct 1, 2026 · @유도일

## 사용법

공통 블록 A\~D + 단계별 프롬프트 3개로 구성. 한 번에 다 돌리지 말고 1→2→3 순서로 실행.

1. **사전 준비**: 아래 체크리스트 완료 (체크리스트는 프롬프트에 붙이지 않음)
2. **1단계**: \[공통 A\~D\] + \[1단계\] 붙여넣기 + 자료 첨부
3. **2단계**: 같은 대화면 \[2단계\]만. 새 대화면 \[공통 A\~C\] + 1단계 '인계 요약' + \[2단계\] + 화면 자료
4. **3단계**: 같은 대화면 \[3단계\]만. 새 대화면 \[공통 A\~C\] + 1·2단계 인계 요약 + \[3단계\]

한 번에 돌려야 하면 공통 → 1 → 2 → 3 순서로 이어 붙이면 됨. 단, 길어질수록 항목당 분석이 얕아짐.

### 사전 준비 체크리스트 (개발자용)

- [ ] 공통 B 입력 양식 채우기. 모르는 항목은 '없음'
- [ ] 골든 세트 참조값: NuDat 3 또는 IAEA LiveChart에서 직접 조회 → 값·불확도·출처·조회일 기입
- [ ] 골든 세트 프로그램 출력값: 화면에 보이는 그대로 (반올림·단위 포함)
- [ ] (권장) 전수 비교: LiveChart API로 전체 바닥상태 CSV 받기 → 내 데이터와 Z·N 기준 매칭 → 반감기·붕괴 방식·분기비·질량 불일치 목록 작성. 이성질체는 별도 확인. 주소: `https://nds.iaea.org/relnsd/v1/data?fields=ground_states&nuclides=all`
- [ ] 화면 자료: 메인 차트 / 셀 확대 / hover / 상세 패널 / 검색 결과 / 붕괴 사슬. 단계별 캡처 또는 화면 녹화
- [ ] (권장) 2단계 시나리오 A\~I를 직접 해보고 클릭 경로 기록 → 조작 단계 수의 근거
- [ ] 웹 검색 되는 모델이면 켜기. 단, 수치 판정은 첨부한 참조값 우선

## 공통 A. 역할과 목표

당신은 동위원소·핵물리·핵화학 데이터를 실제 연구·실무에 쓰는 전문가 패널입니다. 아래 사용자군 관점을 섞지 말고 각각 적용하고, 모든 지적에 관점 태그를 붙일 것.

| 태그 | 사용자군 |
| --- | --- |
| \[교육\] | 교육자·학생 (Chart of Nuclides / Table of Isotopes 학습용) |
| \[방사화학\] | 핵화학·방사화학 연구자 |
| \[핵물리\] | 핵구조·핵천체 연구자 |
| \[질량분석\] | 질량분석·동위원소 지구화학 |
| \[감마분광\] | 감마분광·방사선안전·환경방사능 |
| \[핵의학\] | 핵의학·방사성의약품 |
| \[원자로\] | 원자로·방사화 분석·동위원소 생산 |

**검증 대상**: 제가 만든 동위원소 지도(Nuclide Chart / Chart of Nuclides) 조회·탐색 프로그램. 상세는 공통 B.

**가중치**: 공통 B의 목표 사용자 1순위 > 2순위 > 나머지. 목표 밖 사용자군 의견은 '참고'로만.

**핵심 질문**

> 목표 사용자가 기존 도구(IAEA LiveChart, NNDC NuDat 3, KAERI Table of Nuclides 등) 대신 또는 함께 이 프로그램을 업무에 쓸 이유가 있는가?

**평가 원칙**

- 칭찬 목적 평가 금지. 보기 좋은 UI, 많은 기능 = 가점 아님
- 판단 우선순위: 과학적 정확성 > 데이터 신뢰성 > 정보 접근 속도 > 사용성
- 반대쪽 편향도 금지: 근거 없는 지적, 목표 범위 밖 기능 부재를 결함으로 몰기
- 범위 존중: 공통 B의 '범위'가 지도형 탐색이면 상세 데이터 표(준위 도식 등) 기준으로 감점 금지. 단, 그 범위 때문에 목표 사용자가 핵심 업무를 못 하면 지적
- 추측과 사실 구분: 공통 C의 근거 라벨 사용
- 답변은 한국어. 핵종·단위·기호는 국제 표기 (예: ¹³⁷Cs, keV, T½)

#### 안정 기준

**핵심: 반감기 길이로 자르지 말고, "붕괴가 관측됐냐"로 판정**

반감기 컷오프(예: 10²⁰년 이상 = 안정)로 하면 기준이 자의적이 되고, 새 측정 나올 때마다 꼬임.
→ 예: **²⁰⁹Bi**는 2003년까지 "안정"이었다가 α붕괴 관측됨 (T½ ≈ 2×10¹⁹년)

##### 추천: 4단계 분류

| 분류 | 판정 기준 | 예 | 표시 |
|---|---|---|---|
| **안정** | 붕괴 관측 X, 붕괴 모드 없음 | ¹²C, ¹⁶O | 검정 |
| **관측적 안정** | 붕괴 관측 X, 근데 에너지상 붕괴 가능 (하한만 있음) | ¹⁸⁰ᵐTa, ¹³⁶Xe 이전 등 | 검정 + 작은 마크 |
| **원시 방사성** | 붕괴 관측 O + **자연존재비 있음** | ²³⁸U, ⁴⁰K, ²⁰⁹Bi | 붕괴색 + 검정 띠 |
| **방사성** | 나머지 | 대부분 | 붕괴색 |

- 화면에선 1·2를 같은 "안정"으로 묶어도 됨. **데이터엔 구분해서 저장**
- 원시 방사성도 반감기 컷오프 대신 **자연존재비 유무**로 판정 → 깔끔

##### NUBASE 쓰면 이렇게 판정
- 반감기 필드 `stbl` → 안정 계열
  - 붕괴 모드에 `?` 붙은 게 있음 or 하한(`>`)만 있음 → **관측적 안정**
  - 아무것도 없음 → **안정**
- 반감기 수치 있음 + `IS=` (존재비) 있음 → **원시 방사성**
- 그 외 → 방사성

##### 주의
- **하드코딩 금지** — 판정은 데이터 플래그에서. 데이터 업데이트되면 자동 반영되게
- **이성질체에도 같은 규칙** 적용 → ¹⁸⁰ᵐTa 자동으로 처리됨
- **양성자 붕괴** 같은 이론상 붕괴는 무시. 관측 기준 유지

## 1단계 프롬프트: 니즈 기준 + 데이터·과학 검증

공통 A\~D와 첨부 자료로 아래를 수행. 공통 C 규칙 준수.

### 1-0. 입력 점검

- 공통 B에서 비었거나 모호한 항목 → 그 때문에 판정할 수 없는 항목 나열
- 진행 가능한 범위만 진행. 빈칸을 추측으로 메우지 말 것

### 1-1. 니즈 기준표

실제 사용자가 동위원소 지도를 쓰는 목적을 정리하고, 사용자군별 중요도(필수 / 중요 / 유용 / 해당 없음)를 매길 것. 아래에 없는 니즈가 있으면 추가.

- 기본 조회: 핵종 기본 정보 / Z·N 기준 탐색 / 주변 핵종 탐색 / 핵종 간 비교
- 안정성·붕괴: 안정·방사성 구분 / 반감기 / 붕괴 방식·분기비 / 모·딸 관계 / 붕괴 사슬
- 질량·구조: 질량·질량초과·결합에너지 / Q값 / 스핀·패리티 / 이성질체
- 존재비: 자연 존재비 + 자연 변동 범위
- 방사선: γ·X·α·β 에너지·세기 / 에너지로 핵종 역검색 / β⁺ 분율과 EC 구분
- 반응·생성: 핵반응·생성 경로 / 열중성자 단면적 / 핵분열 수율
- 질량분석: 동중원소(같은 A)·동중성자핵(같은 N) 탐색 → 동중원소 간섭 확인
- 계산: 잔존량·비방사능·방사평형
- 연구 작업: 인용용 복사(값 + 불확도 + 출처 + 버전) / 데이터 내보내기 / 핵종별 고유 링크
- 핵구조 연구: 계통성 추세(S₂ₙ 등) / 마법수·드립라인 표시
- 접근성: 검색 입력 형식(¹³⁷Cs, 137Cs, Cs-137, Cs137, Tc-99m, 99mTc, 한글명) / 한국어 UI면 원소명·용어 표준

출력

- 표: 니즈 × \[교육\] \[방사화학\] \[핵물리\] \[질량분석\] \[감마분광\] \[핵의학\] \[원자로\]
- 목표 사용자(1·2순위) 기준 '필수' 니즈 목록 → 2·3단계 평가 기준으로 사용

### 1-2. 필드별 과학 검증

대상 필드: 원소기호, Z, N, A, 원자질량, 질량초과, 결합에너지, 안정성, 반감기, 붕괴 방식, 분기비, 딸핵종, 자연 존재비, 스핀·패리티, Q값, 이성질체 여기에너지, 방사선 방출 데이터, 열중성자 단면적

출력 표: 필드 / 제공 여부 / 정의 / 단위 / 표현상 오해 소지 / 판정 / 심각도 / 근거

반드시 확인할 함정

- 실험값 vs 추정값·이론 예측: NUBASE는 실험값 없는 핵종에 주변 추세 기반 추정값을 넣고 '#'로 표시. 프로그램이 이 구분을 지우는지
- J^π 괄호 = 잠정 할당. 괄호가 빠지면 확정값처럼 보임
- 한계값(>, <, \~), 비대칭 불확도, 괄호 불확도 표기(예: 12.32(2) y) 해석
- β⁺ 기호: EC + 양전자 합산을 출처마다 다른 기호로 씀 (NUBASE는 β⁺ = EC + 양전자). 프로그램 내 정의 명시 여부, 양전자 분율 별도 제공 여부
- 이성질체: 수록 기준 명시 여부 (출처마다 다름. 예: NUBASE2020은 T½ ≥ 100 ns, Atlas of Nuclear Isomers는 ≥ 10 ns), m / m1 / m2 등 출처별 표기 차이, 바닥상태보다 오래 사는 이성질체 처리
- 비속박 초단수명 핵종: 반감기 대신 준위 폭(eV·keV)이 주어지는 경우 → 시간 단위로 잘못 파싱
- 반감기 단위: ys\~Ey 전 범위 변환, 연(y) 환산 정의 일관성, 반올림·유효숫자 손실
- 질량: 원자질량 / 핵질량 / 이온 질량 구분 라벨 (AME 표는 원자질량)
- 안정 판정: '관측상 안정' 포함 여부, 초장반감기 방사성(²⁰⁹Bi, ¹³⁰Te 등) 처리
- 다중 붕괴: 분기비 합, 소분기(<1%) 누락, 딸이 이성질체로 가는 분기(¹³⁷Cs → ¹³⁷ᵐBa)
- 딸핵종 자동 계산 예외: SF(단일 딸 없음), β⁻n(A−1), 2β⁻(Z+2), 클러스터 붕괴, p·2p 방출
- Q값: 붕괴 방식별 구분, 이성질체 붕괴 시 여기에너지 반영
- 존재비: 몰분율(atom %) 여부와 불확도. CIAAW가 원자량을 구간으로 주는 원소(H, Li, B, C, N, O, S, Pb 등)를 단일값으로만 보여주는지, 조성이 변형된 시판 시료(Li 등) 경고 여부

### 1-3. 골든 세트 판정 (공통 D)

- 핵종별 판정: 일치 / 불일치(불확도 밖) / 표현 오류 / 미제공 / 확인 불가
- 일치 기준: 참조값 불확도 범위 안. 반올림·유효숫자 손실은 따로 기록
- 불일치마다 원인 추정: 버전 차이 / 단위 / 이성질체 매칭 / 파싱 / 실제 오류

출력 표: 핵종 / 항목 / 프로그램 값 / 참조값 / 판정 / 원인 추정 / 심각도

### 1-4. 전수 비교 해석 (diff가 있을 때만)

- 불일치 유형별 건수·패턴
- 원인 추정: 파서 버그, 버전 차이, 이성질체 매칭 등
- 우선 수정 대상

### 1-5. 데이터 출처·관리

- 필드별 현재 출처 신뢰성 평가
- 출처 혼용 시 내부 불일치 위험 (예: AME 질량으로 계산한 Q값 vs ENSDF Q값, NUBASE vs ENSDF 반감기)
- 아래 용도별 기준 출처와 비교

| 용도 | 기준 출처 |
| --- | --- |
| 핵구조·붕괴 | ENSDF (NNDC NuDat 3, IAEA LiveChart로 조회) |
| 바닥상태·이성질체 기본 성질 / 질량 | NUBASE / AME (4\~5년 주기 개정) |
| 계측·감마분광용 붕괴 데이터 | DDEP (LNHB) |
| 존재비·원자량 | CIAAW / IUPAC |
| 원자로 응용 | ENDF/B, JEFF, JENDL |
| 최신 미평가 측정 | XUNDL |
| 지구연대학 | ⁸⁷Rb, ¹⁷⁶Lu 등은 별도 권고 붕괴상수 사용 → 핵데이터 평가값과 다를 수 있음 |

- 필수 관리 요소 점검: 버전 표시 / 필드 단위 출처 표시 / 추출일·업데이트 주기 / 실험·추정 구분 / 불확도 / 변경 이력 / 데이터 라이선스·재배포 조건 / 인용 문구

### 1-6. 오류·위험 요소

전문가가 믿고 썼을 때 잘못된 판단으로 이어지는 경우를 엄격하게 찾아 이슈 카드로 작성.

점검 대상: 잘못된 값 / 오래된 버전 / 단위 혼동 / 안정·방사성 오분류 / 이성질체 누락 / 붕괴 분기 누락 / 반감기 단위 혼동 / 출처 간 값 차이 / 불확도 누락 / 추정값의 측정값화 / 한계값의 확정값화 / 반올림 손실 / 단위가 섞인 정렬 / 붕괴 사슬 종결·순환 오류

### 1단계 출력 순서

1. TOP 5 표
2. 입력 점검 결과
3. 니즈 기준표 + 목표 사용자 필수 니즈
4. 필드 검증표
5. 골든 세트 판정표
6. 전수 비교 해석 (있으면)
7. 데이터 출처·관리 평가
8. 위험 요소 이슈 카드
9. 다음 단계 인계 요약 (10줄 이내)

## 2단계 프롬프트: 차트 사용성 + 업무 시나리오

1단계 결과, 특히 '목표 사용자 필수 니즈'를 기준으로 평가. 공통 C 규칙 준수. 조작 단계 수는 캡처·녹화·클릭 경로 기록으로 확인된 것만 \[확인됨\], 나머지는 \[추정\].

### 2-1. 첫인상 테스트

기존 Chart of Nuclides 사용자가 설명 없이 바로 쓸 수 있는가? 판정: 예 / 부분 / 아니오 + 근거.

점검 항목

- 축: N 가로·Z 세로 배치(관례), Z·N 눈금, 원소 라벨
- 셀: 정보량, 크기, 확대 단계별 표시 내용
- 색: 관례 준수 여부. Karlsruhe 관례 = 안정 검정, β⁺/EC 빨강, β⁻ 파랑, α 노랑, IT 흰색, 다중 붕괴는 분기비 5% 기준 삼각형 크기. 관례와 다르면 오독 위험으로 판정
- 반감기 색 모드, 범례, 확대·축소, 이동
- 검색: 허용 입력 형식, 이성질체 검색, 대소문자·오타 처리
- 원소별 탐색, hover 정보, 클릭 상세, 주변 핵종 비교
- 보조선: 동중원소(같은 A)·동중성자(같은 N) 선, 마법수, 드립라인
- (선택) 색각 이상 대응

### 2-2. 업무 시나리오

범위 밖 시나리오는 '범위 밖'으로 표시하고, 목표 사용자에게 치명적인지만 판단.

| ID | 상황 | 성공 조건 |
| --- | --- | --- |
| A | ¹³⁷Cs 기본 조회 | 반감기(단위·불확도), 붕괴 방식, 딸 ¹³⁷ᵐBa / ¹³⁷Ba 분기 확인. 662 keV γ가 ¹³⁷ᵐBa에서 나온다는 걸 알 수 있음 |
| B | K, Te 원소 내 비교 | 안정 / 자연 존재 / 방사성 구분. ⁴⁰K(자연 방사성), ¹²⁸Te·¹³⁰Te(자연 존재 + 이중베타붕괴) 올바른 분류 |
| C | Sn 사슬 ¹⁰⁰Sn\~¹³²Sn 탐색 | 양성자 과잉 ↔ 중성자 과잉 이동, 마법수 50·82 인지, 추정값(#) 구분 |
| D | ²³⁸U → ²⁰⁶Pb 붕괴 사슬 | 전 경로, 분기(²¹⁸Po, ²¹⁴Bi 등)와 분기비, ²³⁴ᵐPa 처리, 종점 안정 핵종 |
| E | Pb 질량·존재비 | 원자질량(라벨 포함), 존재비 + 변동 구간 경고, 동위원소 간 질량 차이 |
| F | 감마 역검색: 1173·1332 keV 피크 | ⁶⁰Co에 도달 |
| G | 생성 경로: ⁵⁹Co(n,γ)⁶⁰Co | 반응 경로 + 열중성자 단면적 확인 |
| H | 동중원소 간섭: A = 87 | ⁸⁷Rb·⁸⁷Sr 구분, 둘의 질량 차이 확인 |
| I | 인용 | ¹³⁷Cs 반감기를 불확도·출처·버전 포함해 복사 |

시나리오마다: 가능 여부 / 조작 단계 수 \[근거\] / 부족한 정보 / 혼동 가능성 / 개선 / 결과(성공 · 부분 · 실패 · 확인 불가)

### 2-3. 사용성 이슈

이슈 카드로 작성. 색·표시 때문에 생기는 '잘못된 해석' 위험은 심각도를 높게.

### 2단계 출력 순서

1. TOP 5 표
2. 첫인상 테스트 판정 + 근거
3. 시나리오 결과표: ID / 결과 / 단계 수 / 핵심 문제
4. 시나리오별 상세
5. 사용성 이슈 카드
6. 다음 단계 인계 요약 (10줄 이내)

## 3단계 프롬프트: 기존 도구 비교 + 최종 판정

1·2단계 결과를 근거로 평가. 공통 C 규칙 준수. 출력 맨 앞에 핵심 질문에 대한 최종 한 줄 판정 + TOP 5.

### 3-1. 기존 도구 비교

비교 대상

- IAEA LiveChart of Nuclides
- NNDC NuDat 3
- KAERI Table of Nuclides
- Karlsruhe Nuclide Chart (인쇄판, 온라인은 Nucleonica 유료)
- 감마·알파 스펙트럼 조회: LNHB LARAWEB

규칙

- 경쟁 도구 기능은 직접 확인한 것만 단정. 기억 기반이면 \[추정\]
- 구분: 기존보다 좋은 점 / 비슷한 점 / 부족한 점. 해당 없으면 '없음'
- 공통 B의 '내가 생각하는 차별점' → 지지 / 반박 / 불확실 + 근거

반드시 답할 것

- 목표 사용자가 LiveChart·NuDat 대신 이걸 열 이유
- 국내 사용자 대상이면 KAERI 대신 쓸 이유
- 함께 쓴다면 어떤 순간에 이걸 먼저 여는가

### 3-2. 덜어낼 기능

기준 = 목표 사용자가 필요한 정보를 가장 빨리 얻는 것.

- 거의 안 쓰일 기능 / 화면만 복잡하게 하는 기능 / 정보 가치 낮은 기능 / 중요해 보이지만 조회 빈도 낮은 기능
- 정보 계층 제안: 셀에 항상 표시 / hover / 상세 패널 / 숨김

### 3-3. 빠진 핵심 기능

출력 표: 기능 / 필요한 사용자 / 필요한 이유 / 중요도 / 구현 비용(추정) / 우선순위

- 중요도: 필수 / 높음 / 보통 / 낮음
- 구현 비용: 낮음 / 중간 / 높음 (코드 기준 추정)
- 우선순위: P0 치명 이슈 해소·목표 사용자 필수 / P1 핵심 업무 속도 / P2 사용자층 확장 / P3 있으면 좋음

### 3-4. 최종 평가

아래 제목 그대로 작성.

- 현재 가장 잘 구현된 부분: 구체적 이유와 함께
- 실제 전문가가 사용하면서 가장 불편할 부분: 구체적 사용 상황과 함께
- 반드시 수정해야 하는 부분: 과학적 오류 또는 활용을 크게 막는 문제
- 추가하면 가치가 크게 올라가는 기능
- 삭제하거나 단순화해도 되는 부분
- 예상 주요 사용자: 직군·연구 분야
- 현업 활용 가능성: 현재 단계 1개 판정 + 근거 + 다음 단계까지 남은 조건 체크리스트

단계 판정은 아래 진입 조건을 기준으로. 바꿀 필요가 있으면 근거와 함께 수정.

| 단계 | 진입 조건 (아래로 갈수록 누적) |
| --- | --- |
| 교육용 | 핵심 개념(안정성 골짜기, 붕괴 방식, 반감기) 표시가 정확하고 오개념을 만들지 않음. 출처 표시 |
| 학생·연구 입문자용 | + 핵종 검색, 기본 성질 정확, 단위 일관, 안정·방사성·이성질체 올바른 처리 |
| 연구 보조 도구 | + 필드별 출처·버전, 불확도·한계값·추정값 표시, 다중 붕괴 분기, 골든 세트 치명 오류 0건 |
| 전문 연구용 조회 도구 | + 참조 DB 전수 대조(차이 문서화), 목표 사용자 필수 니즈 전부 충족(방사선 방출 데이터 등), 인용·내보내기, 업데이트 체계 |
| 전문 데이터 분석 도구 | + 일괄 조회·API, 붕괴·방사평형 계산, 버전 고정 재현성, 대량 비교·필터 |

### 3-5. 실사용자 검증 계획

이 평가는 전문가 시뮬레이션, 즉 가설. 실제 사용자로 확인할 계획을 작성.

- 모집: 목표 사용자군 3\~5명과 모집 조건
- 테스트 과제 5개: 과제 / 성공 기준 / 제한 시간
- 인터뷰 질문 5개: 지금 쓰는 도구 / 가장 불편한 점 / 갈아탈 조건 / 데이터를 믿으려면 필요한 것 / 시간·비용을 들여서라도 쓸 기능

### 3단계 출력 순서

1. 최종 한 줄 판정 + TOP 5 표
2. 기존 도구 비교
3. 덜어낼 기능 + 정보 계층 제안
4. 빠진 핵심 기능 표
5. 최종 평가
6. 실사용자 검증 계획

## 참고 출처 (프롬프트에 붙이지 않음)

프롬프트 안 과학 기준의 근거. 평가자에게 넘길 필요 없음.

- [Karlsruhe Nuclide Chart – a tradition in progress (EPJ N, 2024)](https://www.epj-n.org/articles/epjn/full_html/2024/01/epjn230026/epjn230026.html): 색 관례, 셀 정보, 대표 온라인 차트

- [Atlas of Nuclear Isomers, 2nd ed.](https://www.sciencedirect.com/science/article/abs/pii/S0092640X22000468): 이성질체 기준 10 ns

- [ANL – Atomic Mass Data Resources](https://www.anl.gov/phy/atomic-mass-data-resources): AME·NUBASE 개정 주기
- [IAEA LiveChart Data Download API](https://www-nds.iaea.org/relnsd/vcharthtml/api_v0_guide.html): CSV 다운로드 API
- [CIAAW – Standard Atomic Weights](https://www.ciaaw.org/atomic-weights.htm): 구간 원자량, 시판 시료 조성 변형
- [ICRM Gamma-spectrometry Introduction (LNHB)](http://www.lnhb.fr/pdf/ICRM_GSWG/2018/Courses/M.C.Lepy_Gamma-spectrometry-Introduction.pdf): ICRM의 DDEP 권고
- [LNHB – DDEP·LARAWEB 소개](http://www.lnhb.fr/pdf/JU2017/JU2017_DDEP.pdf): LARAWEB 스펙트럼 조회
