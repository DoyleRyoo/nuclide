# 남은 골든 항목과 존재비 전수 확인

검증일: 2026-10-02. 1차 [골든 표](../conformity-inspection-2026-10-02/01-data-science.md)에서 보류한 세 항목을 ENSDF·CIAAW 원문으로 확인했다. 존재비는 골든 핵종(Li, Pb)에서 나아가 앱의 존재비 289개 전부를 CIAAW 현재 값과 비교했다.

## 결론

| 항목 | 1차 판정 | 2차 판정 | 근거 |
| --- | --- | --- | --- |
| ²⁴²ᵐAm SF | 표현 차이, ENSDF 확인 필요 | **앱 표시가 맞다.** 참조 API가 `<`를 버렸다 | ENSDF 2022: %SF < 4.7E−9 |
| ²⁹⁴Og SF | 수정 근거로 쓰지 않음 | **앱 표시(`SF ?`)가 ENSDF와 양립한다.** 참조의 20 %는 상한 | ENSDF 2019: α만 관측, %SF ≤ 20 |
| ¹⁸⁰ᵐTa 존재비 | 외부 대조 확인 불가 | **앱 = IUPAC 2013 값.** CIAAW 2017 개정값과 0.6σ 차이 | CIAAW Ta: 0.000 1176(23) |
| Li·Pb 존재비 ± | “±1.71 %를 자연 범위와 동일시하지 않음” | **정정: Li의 ±는 CIAAW 자연 구간을 바꿔 적은 값이다.** Pb는 2021년 CIAAW 개정 전 구간 | NUBASE2020 §2.6, CIAAW |

## 1. ²⁴²ᵐAm 자발 핵분열

- 앱: IT `99.55 ± 0.02 %`, α `0.45 ± 0.02 %`, SF `<4.7×10⁻⁹ %` (1차 [ui-Am-242m.txt](../conformity-inspection-2026-10-02/evidence/ui-Am-242m.txt)).
- ENSDF 채택 문서 (Martin & Nesaraja, Nucl. Data Sheets 186, 261 (2022), cutoff 2021-12-31): %IT = 99.550(10), %α = 0.450(10), **%SF < 4.7E−9**. [NNDC 문서](evidence/golden/242am_adopted.html)
- LiveChart API는 `SF 4.7E-9`로 부등호 없이 준다. 1차에서 “API엔 한계 표기 없음”으로 기록한 차이는 API 쪽 손실이다.
- 판정: 앱의 상한 표기가 맞다. IT·α 불확도(0.02 대 0.010)는 NUBASE가 2002 ENSDF를 바탕으로 한 평가본 차이다. [확인됨]

## 2. ²⁹⁴Og 자발 핵분열

- 앱: `α ~100 %`, `SF ?`, 반감기 `0.7 ± 0.3 ms`.
- ENSDF (Singh, Nucl. Data Sheets 156, 70 (2019)): “Only the α decay mode has been observed. %SF<20 (2016Ho09), <50 (2006Og05).” 채택값 %α = 100, **%SF ≤ 20**. [NNDC 문서](evidence/golden/294og_adopted.html)
- NUBASE `SF ?`는 “에너지상 가능하나 관측되지 않음”이다. ENSDF의 “α만 관측, SF는 상한”과 같은 내용이다.
- 판정: 앱 표시는 ENSDF와 양립한다. 앱은 SF 상한(≤ 20 %)을 보여 주지 않는데, 이는 NUBASE 원문에 그 상한이 없기 때문이다. 반감기의 비대칭 불확도 대칭화는 NUBASE 주석(“symmetrized from 18Br13=0.58(+0.44-0.18)”)에 따른 것이다. [확인됨]

## 3. ¹⁸⁰ᵐTa 자연 존재비

- 앱: Ta-180m 상태에 `0.01201 ± 0.00032 %`.
- NUBASE2020 §2.6: 존재비는 Meija 외(IUPAC 2013, Pure Appl. Chem. 2016)에서 가져왔다.
- CIAAW 현재 Ta 조성(2017 개정): ¹⁸⁰Ta **0.000 1176(23)** = 0.01176 ± 0.00023 %. [CIAAW Ta](evidence/golden/ciaaw/tantalum.htm)
- 차이 0.00025 %p, 결합 불확도 대비 0.63σ. CIAAW는 이 존재비가 바닥상태가 아닌 이성질체의 것이라고 명시하며, 앱도 이성질체 상태에 붙여 보여 준다.
- 판정: 값은 양립한다. 앱 값은 2017 개정 전 권고값이다. [확인됨]
- 들뜬 에너지 75.3(14) keV(NUBASE, 반응 Q값 유래 `RQ`)와 ENSDF 77.2(12) keV의 차이는 1차 판정(평가 차이, 중간)을 유지한다.

## 4. 존재비 ± 의 의미 — 1차 판정 정정

NUBASE2020 §2.6: “In several cases the IS values are listed in Ref. [20] as an interval [a, b], but in Table I they are given as IS = (a + b)/2 with a variance σ² = (b − a)²/12.”

즉 IUPAC이 구간으로 주는 원소는 **중점 ± (b−a)/√12**로 바뀌어 수록되고, 앱은 이를 `값 ± 불확도`로 보여 준다. 화면의 ±는 측정 불확도가 아니라 자연 변동 구간을 균등분포 표준편차로 바꾼 것이다. 원래 구간은 `중점 ± √3 × σ`로 되돌릴 수 있다.

- ⁶Li: 앱 `4.85 ± 1.71 %` → 되돌린 구간 [1.89, 7.81] %. CIAAW 현재 구간 [1.9, 7.8] %와 같다.
- 1차 골든 표의 “±1.71 %를 자연 범위와 동일시하지 않음”은 **틀린 설명이다.** 정확한 문제는 “앱이 이 ±가 구간 환산값임을 알리지 않아, 사용자가 1σ 측정 불확도로 읽거나 구간을 되돌리지 못한다”는 것이다. 심각도(중간, [질량분석][교육])는 유지한다.

### 업무 영향

- [질량분석]: 납과 아르곤은 시료에 따라 조성이 크게 다르다. 앱의 ²⁰⁶Pb `24.1 ± 3.0 %`를 자연 범위로 읽으면 실제 범위(1.9~86.7 %)를 크게 과소평가한다. 시나리오 E의 1차 판정(부분)을 유지하며 근거를 보강한다.
- [교육]: 구간 원소의 ±를 측정 정밀도로 가르치면 오개념이 된다.

## 5. 개선 제안 (적용하지 않음)

1. 구간 원소는 `4.85 %` 대신 `자연 범위 1.9–7.8 % (CIAAW)`처럼 구간 자체를 보여 주고, 환산 σ는 툴팁으로 돌린다.
2. 존재비 출처 연도를 표시한다(IUPAC 2013 / CIAAW 개정 연도). Pb·Ar처럼 시료 의존성이 큰 원소에는 경고를 붙인다.
3. ²⁸Si·³⁰Si·³²S 불확도는 03 문서의 정정 목록에 포함한다.

## 6. 한계

- CIAAW 페이지는 현재 권고값이다. 앱이 따르는 IUPAC 2013 원표(Meija 2016)는 직접 대조하지 않았고, NUBASE2020 §2.6의 설명과 결과의 일치로 갈음했다.
- 값(불확도) 형식의 CIAAW 불확도가 확장 불확도인지 표준 불확도인지 구분하지 않고 비교했다. 2σ 판정은 보수적인 선별이다.
