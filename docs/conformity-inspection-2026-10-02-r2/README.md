## 새로 찾은 것

- **원문 오기:** 붕괴 분기 4건(¹⁶⁴Ho, ¹⁸²Pt, ¹⁵¹Ho, ²¹⁷Pa), 반감기 값 1건(¹³⁸Cs, 확신 중간), 불확도 자릿수 7건(¹¹⁵Rh, ¹⁸⁷Ta, ⁸⁶Ge, ¹²¹Inⁿ, ²⁸Si, ³⁰Si, ³²S). NUBASE2016과 대조하면 ¹⁸⁷Ta를 뺀 11건은 2020판에서 처음 생긴 값·표기다. 정오표는 찾지 못했다.
- **앱 표시 결함:** ⁸⁴Sr 존재비 `00.56 %` (원문 `IS=00.56`을 정규화하지 않음).
- **비교 도구의 한계:** LiveChart API는 분기비의 `>`, `<`, `≈`, `CA`를 버린다. 한계값·근삿값이 측정값처럼 비교된다.
- **존재비 버전:** 앱의 존재비 289개는 CIAAW 현재 값과 2σ 안에서 모두 양립하지만, Pb(2021 개정)·Ar(지구 시료 구간)은 자연 변동 폭이 크게 다르다.
