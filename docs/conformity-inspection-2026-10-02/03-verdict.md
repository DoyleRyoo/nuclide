## 1. 기존 도구 비교

### 사용자가 이 앱을 열 이유

- **LiveChart·NuDat 대신 여는 경우:** 한국어로 핵종의 위치와 기본 반감기를 먼저 찾고, 주변 핵종으로 이동하는 입문·설명 상황은 후보가 된다. 그러나 과학 의미 수정 전에는 전문 평가값을 대신 확인하는 도구로 추천할 근거가 부족하다. [추정: 니즈와 직접 확인 UI의 대응]
- **KAERI 대신 여는 경우:** 단면적/반응이 필요 없는 기본 지도 탐색에서 한국어 안내와 이미 캐시된 오프라인 자료를 쓰려는 경우다. Co(n,γ)처럼 반응 자료를 찾는 업무에서는 KAERI 흐름을 대체하지 못한다. [확인됨: 앱 E2E 오프라인 통과와 G의 미제공; 추정: 선택 선호]
- **함께 쓰는 경우:** 먼저 위치·핵종명·기본 상태를 확인하고, 방출선/준위/평가 이력/반응이 필요하면 목적별 공식 DB로 넘어가는 흐름이 적합하다. 현재는 해당 핵종으로 연결되는 외부 상세 링크와 필드 출처가 보강되어야 한다. [추정: 사용자 흐름 제안]

### 차별점 검토

공통 B의 “개발자가 생각하는 차별점”은 직접 입력이 없어 **확인 불가**다. 기존 기획 문서의 한국어·지도 탐색·오프라인 방향은 검증 가능한 가설로만 취급했다.

## 4. 최종 평가

### 현재 가장 잘 구현된 부분

원본 NUBASE/AME의 값·단위·불확도·#·한계값을 대체로 유지하면서 한글 검색, Z/N 지도, 상태 펼침, 상세 질량·에너지 조회를 연결했다. 5,657개 상태의 식별 키·A=Z+N 검사 및 원본 기반 재생성 검사는 통과했다. 밝은 테마의 대표 색·마법수·행 검색은 실제 화면에서 확인했다. [확인됨: 데이터 profile, data-check, UI 증거]

이 장점은 과학적 의미 오류가 없다는 뜻과 다르다. 원본 숫자를 정확히 보존해도 그것이 전체 비율인지 최종 수율인지 알려주지 않으면 오독이 생긴다.

### 실제 전문가가 사용하면서 가장 불편할 부분

Hf-178m2를 검색한 뒤 기저 상태의 안정 배지·AME 값과 들뜬 상태 값을 분리해서 읽어야 한다. Cs-137에서 Ba 링크로 이동해도 feeding/γ 귀속을 완성하지 못한다. 필요한 값을 찾아도 인용문은 직접 조립해야 한다. [확인됨: A/I 및 SCI-04/05; 추정: 실제 업무 부담 정도]

감마·반응 전문가는 F/G를 이 앱 안에서 완료할 수 없다. 이는 해당 분야의 단독 업무 도구로는 부적합하다는 뜻이며 기본 지도 프로젝트가 반드시 모든 기능을 넣어야 한다는 뜻은 아니다.

### 반드시 수정해야 하는 부분

SCI-01/02의 붕괴 의미 표시, SCI-03의 관측 상태 보존, SCI-04/05의 상태 문맥, UX-01/02의 검색 상태 식별을 먼저 해결해야 한다. [확인됨: 재현 증거]

자료 갱신은 별개다. “LiveChart와 다르다”만으로 NUBASE2020 값을 덮어쓰지 말고 평가 이력·원본 정의·불확도·상태 배정을 비교해야 한다. 기존 단위 혼동 경보 세 건에는 코드의 τ↔T½ 변환 실수라는 증거가 없었다.

### 추가하면 가치가 크게 올라가는 기능

목적별 공식 DB의 해당 핵종으로 이동, 상태를 포함한 값·불확도·출처의 인용 복사, A 검색과 작은 비교표가 현재 범위에서 먼저 검증할 후보이다. [추정: A/H/I의 관찰한 작업 단절에 기반]

방출선·단면적·평형 계산은 사용자층과 데이터 관리 책임을 확정한 후 별도 추진할 항목이다. 추가 기능 수를 성숙도 점수로 사용하지 않았다.

### 삭제하거나 단순화해도 되는 부분

강제 삭제를 권할 사용 빈도 증거는 없다. 교육 중심이라면 질량·Q·분리에너지 묶음을 접고 발견 연도·보조 환산의 시각적 비중을 줄이는 실험이 적절하다. 불확도·추정·상한/하한·상태·출처는 유지해야 한다. [추정: 니즈 기준; 실제 빈도 확인 불가]

### 예상 주요 사용자

한글로 핵종 지도와 방사성/자연 존재 개념을 배우는 학생·교사, 핵·방사화학 입문자, 공식 평가 DB를 병행하는 기본 조회 사용자가 후보이다. 이는 기존 요구 문서와 현재 기능에서 도출한 **추정**이며 개발자가 정한 1·2순위가 아니다.

정밀 계측·핵의학 수율·원자로 반응·질량분석 정량 업무의 단독 도구라는 판단은 현재 근거로 지지할 수 없다.

### 현업 활용 가능성

**현재 단계: 교육용 진입 전 검증 시제품.** 제공된 단계표에 최하위 기준 미충족 상태가 없어 이 단계를 추가했다. 교육용 진입 조건인 “핵심 붕괴 개념이 정확하고 오개념을 만들지 않음”을 SCI-01/02가 충족하지 못한다. UI가 잘 작동하고 단위 테스트가 통과했다는 이유로 교육용을 통과 처리하지 않았다. [확인됨: 골든 세트 표현 오류]

교육용 진입까지의 조건:

- [ ] SCI-01/02: Li-11/F-18/Cu-64/K-40에서 전체·부분 경로와 EC+β+ 정의가 정확히 읽힌다.
- [ ] SCI-03: 관측 세기 미상과 미관측 허용 경로를 데이터와 화면 모두에서 구별한다.
- [ ] SCI-04/05: Cs/Ba와 Tc/Hf 사례에서 선택/딸 상태 및 기저 Q값의 범위가 명확하다.
- [ ] UX-01/02: 없는 이성질체를 다른 상태로 대신 선택하지 않고 m2 입력 형식을 처리한다.
- [ ] 원본 값의 불확도·한계·#·잠정 Jπ가 변경 후에도 보존된다.
- [ ] 골든 세트에 확인된 치명 표현 오류가 없고 재검증 결과가 기록된다.
- [ ] QA-01을 원인별로 해결하거나 지원 환경·테스트 전제의 합당한 예외를 문서화한다.
- [ ] 교육 사용자 테스트에서 자연 존재≠안정, β+/EC, 이성질체를 올바르게 설명한다.

그 다음 연구 보조 단계에는 필드별 근거·인용, 목표 사용자 확정, 전수 상위 플래그의 평가 차이 설명, 갱신 절차가 추가로 필요하다. 전문 분석 단계의 수치 계산 기능은 현재 평가 범위 밖이다.

## 5. 실사용자 검증 계획

이 보고서의 니즈·선호·작업 부담 판단은 가설이다. 아직 모집·연락·테스트를 수행하지 않았다. 다음 계획의 제한 시간은 **설계 제안**이며 실제 측정값이 아니다.

### 모집: 4명, 필요하면 5명

교육 사용자 2명(핵종 지도를 가르치는 교사/조교 1명, 이를 배운 학생 1명), 주기적으로 핵데이터를 조회하는 핵물리 또는 방사화학 연구자 1명, 감마분광 실무자 1명을 기본으로 한다. 질량분석을 주 사용자로 선택하면 해당 실무자 1명을 추가한다. 개발에 참여하지 않았고 최근 3개월 실제 조회 경험이 있는 사람을 우선한다. 목표 순위 확정 후 표본 구성은 바꾼다.

같은 데이터 버전을 제시하고 앱/기존 도구 순서를 교대로 배정한다. 성공 여부, 주요 조작 수, 완료 시간, 오독 종류, 외부 도구 전환 지점을 기록한다. 3~5명의 결과를 모집단 성능 통계처럼 일반화하지 않는다.

치명 오독은 시간과 별도로 기록한다. 예를 들어 F-18의 β+100%를 순수 양전자 방출확률이라고 답하면 빨리 끝나도 성공이 아니다. 미제공 기능에 대해 적절한 외부 도구를 찾는 행동도 기록하되 “앱 안에서 완료”와 분리한다.
