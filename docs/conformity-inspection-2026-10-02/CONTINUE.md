## 남은 심층 검증 — 다음 세션 우선순위

1. **QA-01 원인 구분:** 지연 글꼴 테스트는 woff2 해제 후 `--ruler-w`가 반드시 달라진다고 가정한다. Pretendard import와 폰트 이벤트 재측정 코드는 존재하고 모든 요청이 HTTP 200이다. 실제 적용 시점·선택 글꼴·반올림 후 동일 폭·이벤트 실행을 구별할 증거가 더 필요하다. 기존 trace부터 읽고, 진단을 위해 제품/테스트 코드를 수정하지 않는다. 별도 수정 요청이 있으면 그때 범위를 정한다.
2. **318개 상위 자동 플래그 분류:** `evidence/livechart-diff/diff_details.csv`를 severity로 필터하고 핵종·필드별 NUBASE 원문, ENSDF 평가 cutoff, 실험 근거를 대조한다. 출력은 별도 docs/ 표에 값/불확도/상태/평가 차이/원인/확신 수준을 적는다. 원인 미확정 항목을 버그로 세지 않는다.
3. **남은 골든 해석:** Am-242m SF 한계, Og-294 SF 표기, Ta-180m 자연 존재비의 독립 평가 근거를 원문에서 확인한다. 전체 이성질체 2,099개의 외부 전수 검증은 별도 규모의 작업이다.
4. **목표 순위와 실사용자 검증:** 개발자가 1·2순위 사용자군을 정한 다음 3단계의 4명(선택 5명)·5과제 계획을 시행한다. 실제 사람에게 연락하는 것은 별도 명시적 요청 없이 수행하지 않는다.
5. **도구 비교 보강:** LARAWEB 현행 화면 접근이 가능해지면 F 과제를 확인하고, 동일 과제를 LiveChart/NuDat/KAERI에서 실제 실행해 성공률·시간을 비교한다. 공식 메뉴 열람을 완료 과제 실험으로 대체하지 않는다.

위 항목은 이번 보고서에서 명시적으로 남긴 한계다. 세 단계 보고서 작성과 현재 증거 기반 판정은 완료했으며, 아직 실행하지 않은 추가 검증을 완료로 표시하지 않았다.
