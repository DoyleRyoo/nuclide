## 2. 마일스톤 상세

### M0. 프로젝트 준비

- `git init`, `.gitignore`, Vite + React + TypeScript 초기화, [05 §3](05-architecture.md#3-폴더-구조)의 폴더 구조.
- ESLint, Prettier, Vitest, Playwright 설정. `ci.yml` 뼈대.
- 설계 문서(`docs/`)를 첫 커밋에 포함.

**완료 기준**: `npm run dev`로 빈 화면이 뜬다. `lint`, `test`, `build`가 통과하고 CI가 녹색이다.

### M1. 데이터 파이프라인

- `data/raw/`에 원본 4개 + `data/SOURCES.md`.
- `parseNubase.ts`, `decayModes.ts`, `parseAme.ts`(패널 표시는 P1이지만 파서는 함께 만든다), `validate.ts`.
- `src/data/types.ts`(04 §7), `src/data/elements.ts`(119행, 한/영 이름, 별칭).
- `npm run data:build`, `npm run data:check`.

**완료 기준**: 04 §11의 검증과 골든 테스트가 모두 통과한다. 데이터 JSON이 gzip 250 KB 이하다.

### M2. 차트 엔진 코어

- `camera.ts` + 속성 테스트, `Renderer`(레이어 2개, 필요할 때만 그리기), 칸 렌더링(컬링·색 배칭·LOD 0).
- 입력: 휠 세로/가로 이동, Ctrl/⌘+휠·트랙패드 핀치(Safari 포함) 줌, 드래그, 클릭/드래그 판별.
- 배율·이동 범위 제한, 전체 보기, 히트 테스트, 호버 링, 눈금자, 마법수 선, `?debug=1` 오버레이.

**완료 기준**: FR-01~07, 25, 40, 42, 43 충족. 데스크톱에서 60fps 확인. 휠·줌·드래그·클릭 판별 E2E 통과.

### M3. 정보 패널·UI

- LOD 1–3 글자, 선택 링, `ChartView`로 스토어 연결.
- 정보 패널(P0 항목), 범례, 줌 컨트롤, 도구 모음, 도움말·정보 대화상자(출처 표기).
- 모바일: 하단 시트, 터치 핀치·탭·더블탭.
- 테마(OS 설정 추종), i18n 구조(한국어 사전).

**완료 기준**: 모든 P0 FR 충족. 모바일 뷰포트 E2E 통과. 키보드 포커스와 `aria-live` 알림 동작.

### M4. MVP 배포 (v0.1)

- `deploy.yml`, `base` 경로, CSP, 파비콘, README.
- Lighthouse 점검.

**완료 기준**: GitHub Pages에서 동작한다. Lighthouse 성능·접근성 90 이상. §5의 "데이터 이용 조건" 항목을 확인했다.

## 4. 결정 기록 (ADR)

| ID | 결정 | 검토한 대안 | 이유 | 다시 볼 조건 |
|---|---|---|---|---|
| ADR-01 | 데이터를 앱에 내장 | 외부 API 실시간 조회, 자체 서버 + DB | 평가본 갱신 주기 약 4년, 작은 크기, 오프라인·비용·개인정보 이점. d.md의 판단과 같음 | ENSDF급 대용량 데이터를 넣을 때 → 지연 로딩 청크로 분할 |
| ADR-02 | Canvas 2D 자체 엔진 | SVG/DOM, WebGL(PixiJS 등), 지도 라이브러리(Leaflet `CRS.Simple`, MapLibre) | SVG는 3,500개 요소 + 글자로 줌할 때 무거움. WebGL은 글자 처리가 어렵고 복잡함. 지도 라이브러리는 타일 생성이 필요하고 칸 단위 LOD 글자 제어가 어려움. Canvas 2D는 보이는 칸만 그리면 60fps에 충분하고 구현이 단순함 | 저사양 모바일에서 NFR-01 미달 |
| ADR-03 | React UI + React와 분리된 엔진 | 바닐라 TS, Svelte, Vue | 상태가 많은 UI를 컴포넌트로 관리, 가장 넓은 생태계. 차트 경로는 React 밖이라 성능 영향 없음 | — |
| ADR-04 | 휠 = 스크롤, Ctrl/⌘+휠·핀치 = 줌 | 휠 = 줌(지도 앱 방식) | d.md가 가로·세로 휠 스크롤을 줌과 별개 기능으로 요구. Figma·Miro 같은 캔버스 도구의 관례이고 트랙패드에서 자연스러움 | 사용자 반응에 따라 설정의 기본값만 바꿈 |
| ADR-05 | 가로 N, 세로 Z | 가로 Z, 세로 N | 카를스루에·NNDC·IAEA 등 주요 차트의 표준 배치 | — |
| ADR-06 | 카를스루에 색 관례 + 글자 대비 보정 | 임의 팔레트, 색각 친화 팔레트를 기본으로 | 전문가에게 익숙하고 교육 자료와 일치. 색각 친화 팔레트는 선택 사항(P2) | — |
| ADR-07 | NUBASE2020 + AME2020 | ENSDF 전체, NuDat·LiveChart 내보내기 | 공식 평가본, 기저·이성질체의 핵심 성질이 한 파일에 있음, 고정폭 텍스트라 파싱이 쉽고 작음 | 새 평가본 공개 시 교체 |
| ADR-08 | GitHub Pages + PWA | Vercel·Netlify·Cloudflare Pages, 앱스토어 네이티브 먼저 | 무료, 저장소와 통합, 정적 SPA와 잘 맞음. 다른 정적 호스팅으로 옮기기 쉬움 | 사용자 도메인·HTTP 헤더 설정이 필요하면 Cloudflare Pages |
| ADR-09 | 칸 = 기저 상태, 들뜬 상태는 패널에서, IAS 제외 | v1부터 이성질체 분할 칸 | 단순하고 읽기 쉬움. 분할 칸은 P2 | — |
| ADR-10 | 예측(미관측) 핵종을 점선 칸으로 표시, 기본 켬 | 숨김 | 알려진 영역의 경계를 보여 주는 교육적 가치. 설정으로 숨길 수 있음 | 혼란 보고가 있으면 기본 끔 |
| ADR-11 | Zustand | Redux Toolkit, Context만 사용 | 작고, React 밖 엔진에서도 구독 가능 | — |
| ADR-12 | CSS Modules + 토큰 | Tailwind | 토큰을 캔버스와 공유, UI 규모가 작음 | — |
| ADR-13 | AME 값은 불확도 2자리 기준으로 반올림해 표시 | 원문 그대로 표시 | AME 파일은 반올림 전 값(출판 표는 반올림됨) → 가독성 | — |
