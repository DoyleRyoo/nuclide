# 4차 — 목표 사용자·범위를 반영한 재평가

검증일: 2026-10-02. 1~3차는 목표 사용자 순위가 비어 있어 사용자군별 가중치 없이 판정했다. 개발자가 채운 공통 B(1순위 교사·학생, 2순위 관련 종사자, 범위 “둘 다”)로 1차 니즈표·시나리오·우선순위·성숙도를 다시 판정했다. 새 측정은 [01](01-input-check.md)~[03](03-stability-classes.md)이고, 나머지 근거는 1~3차 증거를 그대로 썼다.

2순위 “관련 종사자”는 공통 A 태그가 아니어서 [방사화학][감마분광][핵의학][원자로]로 해석했다 [추정]. 개발자 확인이 필요하다.

## 최종 한 줄 판정

**교사·학생(1순위)에게는 교육용 진입 조건을 아직 충족하지 못한다. 관련 종사자(2순위)에게는 업무 도구가 아니라 위치 확인용 보조 지도 수준이다.** 1순위의 장애는 붕괴 표시 의미(SCI-01/02)와 화면에 그대로 나오는 원문 오기다. 2순위의 장애는 범위 “둘 다”에 포함된 방출선·β⁺ 분율·인용 기능이 없다는 점이다. [확인됨: 1~4차 증거]

## 1. 목표 사용자 필수 니즈와 현재 충족도

| 니즈 | 필수인 사용자 | 현재 | 근거 |
| --- | --- | --- | --- |
| 기본 조회·Z/N·주변 탐색 | 교육, 방사화학, 원자로 | **충족** | 1차 첫인상·검색 |
| 안정/방사성·T½·분기·딸 상태 | 교육, 종사자 전부 | **부분** — SCI-01~04, 원문 오기, 관측적 안정 미구분 | 1·2차, [03](03-stability-classes.md) |
| 한글·표준 검색 형식 | 교육 | **대부분 충족** — m2 질량수 우선 표기 실패(UX-02) | 1차 |
| 이성질체 식별·상태별 값 | 종사자 전부 | **부분** — SCI-05, UX-01/02, 기준 혼재 | [02](02-isomer-criterion.md) |
| 자연 존재비·변동 범위 | 방사화학, 원자로 | **부분** — 구간 의미 미표시, 원문 자릿수 오류(Si·S), Pb 구판 | 2차 04 |

| β⁺ 실제 분율과 EC 구분 | 방사화학, 감마분광, 핵의학 | **미충족** | 1차 SCI-02 |

| 잔존량·비방사능·방사평형 계산 | 종사자 전부 | **미충족** | 1차 B-3 |
| 값·불확도·출처·버전 인용 | 종사자 전부 | **미충족** — 링크 복사만 가능 | 1차 I |

## 3. 차별점 “시각적이고 유저 친화적이다”

| 주장 | 판정 | 근거 |
| --- | --- | --- |
| 시각적이다 | **불확실** | 지도형 탐색·확대·색 모드는 동작한다. 그러나 IAEA LiveChart와 KAERI도 지도형 차트를 제공한다(1차 3단계, 공식 화면 확인 범위). 시각적이라는 점만으로는 기존 도구 대비 차별점이 되지 않는다. 대표 색·이성질체 삼각형의 오독 위험(UX-04)과 관측적 안정 미구분은 시각 표현의 약점이다 |
| 유저 친화적이다 | **부분 지지** | 한국어 UI, 한글 핵종명 검색(세슘-137), 캐시 후 오프라인은 확인됐다. 교사·학생이 실제로 더 쉽게 쓰는지는 측정하지 않았다. 1차 첫인상 판정은 ‘부분’이다 |

검증 가능한 차별점으로 다듬는다면 “한국어로, 설치 없이, 오프라인에서도 핵종 지도와 기본 성질을 교육용 설명과 함께 본다”가 지금 증거로 뒷받침되는 범위다 [추정]. 시각성 우위는 실사용자 시험에서 LiveChart·KAERI와 같은 과제로 비교해야 판정할 수 있다.

## 6. 실사용자 검증 계획 조정

1차 3단계 계획을 1·2순위에 맞춰 바꿨다. 연락·모집은 하지 않았다.

- 모집: 교사 1~2명, 학생 2명(고교·학부), 종사자 2명(방사선안전·감마분광 1, 핵의학 또는 원자로·RI 생산 1).
- 앱과 기존 도구(LiveChart 또는 KAERI)를 교대로 쓰게 해 차별점 “시각적·유저 친화”를 같은 과제로 비교한다.

| 과제 | 성공 기준 | 제한 시간(제안) |
| --- | --- | --- |
| 1. ¹²C, ²⁰⁸Pb, ⁴⁰K, ¹⁸⁰Ta를 안정/관측적 안정/원시 방사성/방사성으로 분류 | 4개 모두 맞고 근거(관측 여부·존재비)를 말한다 | 3분 |
| 2. ¹⁸F의 β⁺와 EC 비율 설명 | EC 포함 합계와 양전자 비율을 구별한다 | 3분 |
| 3. ¹³⁷Cs → ¹³⁷ᵐBa → 662 keV γ | 딸 상태와 γ의 출처를 설명한다(앱 밖 자료 사용 여부 기록) | 4분 |
| 4. ²³⁸U 사슬에서 ²²⁶Ra까지 | 주요 단계와 분기를 찾는다 | 5분 |
| 5. ¹³⁷Cs 반감기를 출처 포함해 기록 | 값·불확도·출처(NUBASE2020)·버전을 함께 남긴다 | 3분 |

## 7. 개발자가 정할 사항 (4차에서 새로 생긴 것)

1. 2순위 “관련 종사자”의 범위(공통 A 태그).
2. 공통 B의 출처·딸핵종·방출·단면적 입력을 앱에 맞출지, 앱을 입력에 맞출지.
3. 범위 “둘 다”를 1순위 출시에도 적용할지, 단계로 나눌지.
4. 이성질체 지도 표식 문턱(권고: 데이터 100 ns, 표식 기본 1 s).
5. 관측적 안정 판정에 AME Q값을 쓸지와, 포함할 붕괴 모드 목록.
6. ‘원시 방사성’ 이름과 ²³⁰Th·²³¹Pa·²³⁴U 처리, ¹⁸⁰Ta 칸 표시.
