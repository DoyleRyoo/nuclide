# 4차 — ‘안정’ 4단계 기준 검증

검증일: 2026-10-02. 개발자가 공통 B에 적은 [안정 기준](../conformity_inspection.md)(안정·관측적 안정·원시 방사성·방사성)의 **NUBASE 판정 규칙을 그대로 구현해** 원문 전체에 적용하고, 앱의 현재 표시와 대조했다. 스크립트 [stability_isomer_audit.py](evidence/stability_isomer_audit.py), 결과 [stability-isomer-audit.json](evidence/stability-isomer-audit.json). 앱 코드는 바꾸지 않았다.

## 결론

- **원칙(반감기 길이가 아니라 붕괴 관측 여부로 판정, 데이터 플래그로 자동 판정)은 과학적으로 맞고 원문 데이터만으로 구현할 수 있다.** 필요한 플래그(`stbl`, `?`, 하한 `>`, `IS=`)는 앱 데이터에 모두 보존돼 있다.
- **다만 NUBASE 규칙만으로는 정의와 어긋나는 결과가 두 군데 나온다.**
  1. ‘안정’으로 분류되는 바닥상태 182개 중 36개는 AME2020 질량으로 α 붕괴가 에너지상 가능하다(Q_α > 0). 정의(“에너지상 붕괴 가능하면 관측적 안정”)대로라면 관측적 안정이다. NUBASE가 이들에 `A ?`를 달지 않았을 뿐이다.
  2. ‘원시 방사성’ 35개 중 ²³⁰Th·²³¹Pa·²³⁴U는 우라늄 붕괴 계열에서 계속 만들어지는 핵종이다. 지구 생성 때부터 남은 것이 아니므로 ‘원시’라는 이름이 맞지 않는다.
- **앱의 현재 표시는 규칙과 대부분 맞는다.** 원시 방사성 35개의 ‘붕괴색 + 검정 띠’까지 이미 구현돼 있다(`src/chart/render/cells.ts:163-171`, `src/data/hydrate.ts:81`). 다른 점은 관측적 안정을 따로 구분하지 않는 것과 ¹⁸⁰Ta 칸의 띠다.

## 문제 1 — ‘붕괴 모드 없음’이 ‘붕괴 불가’를 뜻하지 않는다

NUBASE `?`는 “에너지상 가능하나 미관측” 모드에만 붙지만, 가능한 모드에 빠짐없이 붙는 것은 아니다. ‘안정’ 182개의 바닥상태에 AME2020 질량으로 α·β⁻·EC·2β⁻·2EC의 Q값을 계산했다(3σ로 양수일 때만).

- **36개가 α 붕괴 에너지상 가능**: ¹⁵⁰Sm(Q_α 1,450 keV), ¹⁵²Sm, ¹⁵⁴·¹⁵⁵Gd, ¹⁶⁰⁻¹⁶²Dy, ¹⁶⁵Ho, ¹⁶⁶⁻¹⁶⁸Er, ¹⁶⁹Tm, ¹⁷⁰⁻¹⁷⁴Yb, ¹⁷⁵Lu, ¹⁷⁶·¹⁷⁸⁻¹⁸⁰Hf(¹⁷⁶Hf 2,254 keV), ¹⁸¹Ta, ¹⁸⁵Re, ¹⁹¹·¹⁹³Ir, ¹⁹⁴·¹⁹⁶Pt, ¹⁹⁷Au(972 keV), ¹⁹⁸⁻²⁰²Hg, ²⁰³·²⁰⁵Tl.
- β⁻·EC·2β⁻·2EC로 가능한데 `?`가 없는 경우는 없었다. 이중베타 후보에는 NUBASE가 이미 `?`나 측정 반감기를 붙여 두었다.
- 바닥상태 기준으로 Q값까지 반영하면 안정 146 / 관측적 안정 107이 된다. 입력의 “하드코딩 금지” 원칙과도 맞는다. Q값도 데이터에서 자동으로 계산되기 때문이다.

어떤 붕괴를 ‘가능’으로 셀지는 관례를 정해야 한다. 이번 계산은 α, β⁻, EC, 2β⁻, 2EC만 셌다. 무거운 핵종 대부분은 자발 핵분열·클러스터 방출도 에너지상 가능하므로, 그것까지 세면 ‘안정’은 더 줄어든다. 입력의 “양성자 붕괴 같은 이론상 붕괴는 무시”와 같은 방식으로 기준 목록을 문서에 적어 두기를 권한다.

## 문제 2 — ‘원시’가 아닌 자연 존재 방사성

‘수치 반감기 + 자연존재비’ 35개:

- 원시(지구 생성 이전부터 존재): ⁴⁰K, ⁴⁸Ca, ⁵⁰V, ⁷⁶Ge, ⁸²Se, ⁸⁷Rb, ⁹⁶Zr, ¹⁰⁰Mo, ¹¹³Cd, ¹¹⁶Cd, ¹¹⁵In, ¹²⁸Te, ¹³⁰Te, ¹³⁶Xe, ¹³⁸La, ¹⁴⁴Nd, ¹⁵⁰Nd, ¹⁴⁷Sm, ¹⁴⁸Sm, ¹⁵¹Eu, ¹⁵²Gd, ¹⁷⁴Hf, ¹⁷⁶Lu, ¹⁸⁰W, ¹⁸⁴Os, ¹⁸⁶Os, ¹⁸⁷Re, ¹⁹⁰Pt, ²⁰⁹Bi, ²³²Th, ²³⁵U, ²³⁸U (32개)
- 붕괴 계열에서 생성: **²³⁰Th, ²³¹Pa, ²³⁴U** (3개). 원문에 존재비(IS)가 있어 규칙에 걸린다.

교육 1순위에서 ‘원시’라는 이름은 개념을 가르치는 말이다. 이 3개를 원시로 표시하면 오개념이 된다. 이름을 “자연 존재 방사성”으로 바꾸거나, 붕괴 계열 생성 핵종을 하위 분류로 두는 방법이 있다. 반대로 ¹⁴C·³H(우주선 생성)나 ²²⁶Ra·²²²Rn(계열 생성)은 원문에 존재비가 없어 ‘방사성’으로 남는다. 규칙의 판정 근거가 “원문 존재비”임을 범례에 적어 두면 혼선이 줄어든다.

## 제안 (적용하지 않음)

1. 상태마다 4단계 분류를 데이터 필드로 계산해 저장한다(입력의 “데이터엔 구분해서 저장”).
2. 관측적 안정 판정에 NUBASE `?`·하한과 함께 AME Q값(포함하는 붕괴 모드 목록을 문서화)을 쓴다.
3. ‘원시’ 이름을 고치거나 붕괴 계열 생성 3개를 하위 분류로 둔다.
4. ¹⁸⁰Ta처럼 이성질체만 자연에 있는 경우를 칸에서 어떻게 보일지 정한다(예: 띠 대신 이성질체 표식 색).
