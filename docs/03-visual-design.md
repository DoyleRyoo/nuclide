# 03. 비주얼 디자인

## 1. 디자인 원칙

1. **지도가 주인공** — 차트가 화면 전체를 차지하고, 나머지 UI는 반투명한 떠 있는 카드로 최소화한다.
2. **관례를 따른다** — 색은 카를스루에 핵종도(Karlsruhe Nuclide Chart) 관례를 따른다. 전문가에게 익숙하고, 처음 보는 사람은 범례로 배운다.
3. **확대할수록 더 많이** — 정보는 줌 단계(LOD)에 따라 점점 드러난다.
4. **숫자는 정확하고 읽기 쉽게** — 원문 정밀도 유지, 고정폭 숫자, 단위 병기.
5. **라이트·다크 동등** — 두 테마를 처음부터 같은 수준으로 지원한다.

## 2. 테마 토큰

### 2.2 글꼴

- 서체: **Pretendard Variable** (SIL OFL). npm `pretendard` 패키지의 dynamic subset을 써서 실제로 쓰는 글자 범위만 내려받는다.
- 대체 글꼴: `-apple-system, BlinkMacSystemFont, "Segoe UI", "Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", sans-serif`
- 숫자: UI에서는 `font-variant-numeric: tabular-nums`.
- 크기: 12 / 13 / 14(본문) / 16 / 20 / 24 / 32 px. 굵기: 400 / 500 / 600 / 700. 줄 간격: 본문 1.45, 제목 1.2.
- 캔버스는 글꼴이 로드되기 전에는 대체 글꼴로 그리고, `document.fonts.load()`가 끝나면 한 번 다시 그린다.

| 종류 | 값 |

- 안정·β−·β+/EC·α·SF·p는 카를스루에 관례를 따른다. n·IT·클러스터는 차트마다 관례가 달라 구분이 잘 되는 색으로 정했다.
- 모든 칸에서 글자 대비 4.5:1(WCAG AA) 이상이 되도록 명도를 조정했다(예: 파랑은 `#3B82F6`이면 흰 글자 대비 3.7:1이라 `#2563EB`로 어둡게 했다).
- **안정 칸은 테마에 따라 뒤집힌다**: 라이트에서는 가장 어둡고(검정), 다크에서는 가장 밝다. 어느 테마에서든 안정성 계곡이 차트의 척추로 가장 도드라진다.
- 칸 색은 기저 상태의 **주 붕괴 모드**로 정한다. 주 모드 판정 규칙과 NUBASE 토큰 → 범주 대응표는 [04 §5](04-data.md#5-붕괴-모드-해석)에 있다. IT는 들뜬 상태에만, 클러스터는 부분 분기로만 나오므로 칸 색으로는 쓰이지 않고 패널 배지·화살표에서만 쓴다.

## 4. 연속 색상 스케일

| 모드 | 매핑하는 값 | 색 지도 | 도메인 (밖은 끝 색) | 범례 눈금 | 특수 값 |
|---|---|---|---|---|---|
| 반감기 (P1) | log10(T½ / s) | viridis, t ∈ [0.08, 1] | −9 (1 ns) … 18 (≈ 32 Gy) | 1 ns, 1 μs, 1 ms, 1 s, 1 min, 1 h, 1 d, 1 y, 1 ky, 1 My, 1 Gy | 안정 → 안정 색, 미상 → `--cell-na` |
| 핵자당 결합에너지 (P1) | B/A (keV) | plasma, t ∈ [0.1, 1] | 7,000 … 8,800 keV | 7.0, 7.5, 8.0, 8.5, 8.8 MeV | 값 없음 → `--cell-na` |
| 발견 연도 (P2) | 연도 | cividis | 1896 … 2020 | 1900, 1925, 1950, 1975, 2000, 2020 | 미관측 → `--cell-na` |
| 자연 존재비 (P2) | log10(%) | 청록 단색 명도 스케일 | −4 … 2 (0.0001 % … 100 %) | 0.001, 0.01, 0.1, 1, 10, 100 % | 자연에 없음 → `--cell-na` |

- 반감기 스케일: 짧을수록 어둡고(보라) 길수록 밝다(노랑). viridis 아래쪽 8%는 다크 배경과 구분이 안 돼 잘라 냈다.
- 결합에너지 최댓값은 ⁶²Ni 8,794.6 keV, ⁵⁶Fe 8,790.4 keV (AME2020). 가벼운 핵은 7 MeV보다 작아 최저 색으로 클램프된다. 구현 후 분포를 보고 도메인을 조정한다.
- 한계값(`>`, `<`)은 경계값으로 색을 정한다. 추정값(`#`)도 같은 색을 쓰되 글자에 `#`을 붙인다.
- 색 지도는 `src/theme/colormaps.ts`에서 matplotlib viridis·plasma의 6차 다항식 근사(Matt Zucker, CC0)로 계산하고, 칸 색은 64단계로 양자화한다. 256단계 LUT와의 차이는 채널당 약 1/255 이하다. cividis(P2)는 발견 연도 모드를 만들 때 추가한다.
- 연속 모드의 칸 글자색은 `#111827`과 `#FFFFFF` 중 대비가 큰 쪽을 자동으로 고른다.

## 5. 칸(셀) 디자인

### 5.1 크기·간격·모서리

| 배율 s (px/칸) | 칸 사이 간격 | 모서리 반경 |
|---|---|---|
| s < 6 | 0 (붙여 그림) | 0 |
| 6 ≤ s < 32 | 1px | 0 |

- s ≥ 8에서는 칸 경계를 기기 픽셀에 맞춰(pixel snapping) 가장자리가 흐려지지 않게 한다.
- 라이트 테마에서는 칸마다 1px `--cell-stroke` 테두리를 그린다.

### 5.4 선택·호버·강조

- **선택**: 칸 바깥으로 1px 띄워 2px `--sel-outer` 링, 그 안쪽에 1px `--sel-inner` 링, 그림자(blur 12px, `--accent` 50%). 이중 링이라 어떤 칸 색 위에서도 보인다.
- **호버**: 1.5px `--hover-ring`.
- **범례 호버 강조 (P1)**: 해당 범주가 아닌 칸의 불투명도를 25%로 낮춘다.
- **검색 강조 (행·열)**: 경계 상자에 2px `--accent` 외곽선, 1.2초 동안 두 번 깜빡임.

## 6. 차트 보조 요소

### 6.1 마법수 선

- 두께 1.5px(화면 픽셀 고정), 색 `--magic`, 칸 위에 그린다. 다만 s < 6에서는 두 줄 사이가 몇 px뿐이라 굵은 띠가 되므로 s / 4px(최소 0.75px)로 가늘게 한다(모바일 전체 보기 s ≈ 2).
- 마법수 Z 행: y = Z와 y = Z + 1에 가로선 두 개. 길이는 그 행에 있는 핵종의 N 범위(양 끝 0.5칸 여유).
- 마법수 N 열: x = N과 x = N + 1에 세로선 두 개. 길이는 그 열의 Z 범위.
- 대상: Z = 2, 8, 20, 28, 50, 82 / N = 2, 8, 20, 28, 50, 82, 126 (Z = 126 핵종은 없다).
- LOD 0–1에서는 선 끝에 라벨 "Z=50", "N=82" (11px, `--text-muted`). 라벨끼리 겹치면 큰 마법수 라벨을 남기고 작은 쪽을 생략한다.

### 6.2 N=Z 기준선 (P1)

- 월드 좌표 (0.5, 0.5)에서 (118.5, 118.5)까지, 즉 N = Z 칸의 중심을 잇는 대각선.
- 1px 점선(6-4), `--text-subtle`, 불투명도 60%, 칸 위에 그린다. LOD 3에서는 글자와 겹치므로 생략한다.

### 6.3 붕괴 화살표 (P1)

- 선택 칸 중심 → 딸핵 칸 중심. 칸에 글자가 있는 LOD ≥ 1에서는 선택 칸의 가장자리에서 출발해 글자를 가리지 않는다. 굵기 max(1.5px, 0.04 s), 색 = 붕괴 범주 색(같은 색 칸 위에서도 보이게 바탕색 테두리), 화살촉 길이 max(6px, 0.18 s).
- 분기비가 큰 순서로 최대 5개. 분기비가 `?`이면 점선.
- 분기비가 0.01 % 미만인 분기는 화살표를 생략한다(첫 분기와 세기 미상 `?`는 예외). 예: ²³⁵U의 클러스터 붕괴(10⁻¹⁰ %) 화살표 3개가 지도를 가로질러 α 100 %보다 두드러졌다. 패널에는 모든 분기가 나온다.
- LOD 2 이상에서는 화살표 가운데에 분기비 라벨(12px, `--surface` 배경 알약).
- 딸핵이 데이터에 없으면 점선 화살표 + 목적지에 빈 칸 외곽선.
- SF는 딸핵이 하나로 정해지지 않으므로 화살표 없이 패널에만 표시한다.

- 배경 `--surface`(블러), 지도 쪽 1px `--border`. 라벨은 해당 칸의 중심에 맞춘다.
- 마법수 라벨은 굵게 + `--accent`.
- 호버한 Z/N은 `--accent-weak` 알약 배경, 선택한 Z/N은 `--accent` 배경 + 흰 글자(다크 테마는 검정 글자).
- 왼쪽 아래 모서리(48×28px)에는 "Z / N"을 쓴다.

## 7. UI 컴포넌트

### 7.1 검색창 (P1)

- 높이 44px, 폭 360px(모바일: 화면 폭 − 여백 − 메뉴 버튼), 모서리 `--r-md`, 카드 스타일.
- 왼쪽 돋보기 아이콘, 자리표시자 "핵종 검색 — U-235, 우라늄, 99mTc", 오른쪽에 `/` 키 힌트.
- 후보 목록: 최대 8개, 항목 높이 44px: `[색 점] ²³⁵U  우라늄-235 · 704 My · α`. 고른 항목은 `--surface-hover`.

### 7.2 도구 모음

- 버튼 높이 36px, 카드 하나로 묶는다.
- 색상 모드 드롭다운(현재 모드 이름 + ▾, 메뉴는 라디오 목록), 테마(시스템 → 라이트 → 다크 순환 아이콘), 언어(`한` / `EN`), 도움말(`?`).
- 모바일에서는 ≡ 메뉴 안으로 들어간다.

### 7.3 줌 컨트롤

- 40×40px 버튼 3개를 세로로 붙인 카드, 사이 1px 구분선.
- 아이콘: plus / minus / maximize(전체 보기). 툴팁: "확대 (+)", "축소 (−)", "전체 보기 (0)".
- 배율이 한계면 해당 버튼 비활성.

### 7.4 범례

- 카드 폭 232px. 헤더 "범례 · 붕괴 모드" + 접기 버튼. 데스크톱은 기본 펼침, 모바일은 기본 접힘(칩).
- 범주 행 높이 24px: 14×14px 견본(모서리 3px) + 이름 + 개수(오른쪽 정렬, 고정폭 숫자). 개수는 지금 표시 중인 핵종 기준(예측 핵종 표시 여부 반영).
- 구분선 아래 표식 설명(P1): 이성질체 삼각형, 자연 존재 띠, 예측 점선, `#` 추정값.
- 연속 모드: 200×10px 색 막대 + 눈금 라벨 + "안정"·"값 없음" 견본.

### 7.5 미니맵 (P1)

- 200×134px(178:119 비율), 카드 안쪽 여백 8px, 데스크톱만.
- 전체 차트를 약 1.1 px/칸으로 미리 그린 비트맵을 쓴다(데이터·색상 모드·테마·예측 핵종 표시 설정이 바뀔 때만 다시 그림). 카메라 이동은 비트맵 복사와 영역 사각형만 갱신하며, 영역 크기는 차트 뷰포트 기준이다.
- 현재 보이는 영역: 1.5px `--accent` 사각형 + 12% 채움. 클릭하면 그 지점이 중심이 되게 이동하고, 사각형을 끌면 따라 이동한다.

## 11. 접근성 점검표

- [ ] 모든 UI 글자 대비 4.5:1 이상, 큰 글자·그래픽 요소 3:1 이상
- [ ] 칸 글자 대비 4.5:1 이상 (§3 표, 연속 모드는 자동 선택)
- [ ] 색만으로 정보를 전달하지 않는다: 칸 글자(LOD ≥ 1), 툴팁, 범례 호버 강조, 패널 텍스트

- [ ] 터치 대상 최소 40×40px (모바일 44×44px)
- [ ] `prefers-reduced-motion`에서 카메라 애니메이션·관성 끔
- [ ] 페이지 확대 200%에서 UI가 깨지지 않음
