# Nuclide Map (핵종 지도) — 설계 문서

핵종도(Table of Nuclides)를 **지도처럼** 탐색하는 웹 애플리케이션의 설계 문서 모음이다.
최초 요구사항 메모는 [d.md](../d.md)에 원문 그대로 보존한다.

> "Nuclide Map / 핵종 지도"는 작업용 이름이며 언제든 바꿀 수 있다.

## 한눈에 보기

- 가로축 N(중성자 수), 세로축 Z(양성자 수) 평면에 **관측된 핵종 3,340개**(+ 미관측 예측 핵종 218개)를 칸으로 배치한다.
- 지도 앱처럼 **확대·축소, 휠 가로/세로 스크롤, 드래그 이동**으로 차트 전체에서 핵종 하나까지 끊김 없이 탐색한다.
- 핵종을 **클릭하면** 반감기·붕괴 모드·분기비·자연 존재비·스핀/패리티·질량 등 상세 정보를 패널로 보여준다.
- 데이터(NUBASE2020 + AME2020)는 빌드할 때 JSON으로 변환해 **앱에 내장**한다. 서버·DB·계정이 없고 사용자 데이터를 저장하지 않는다.
- 웹을 먼저 만들고, 같은 코드로 PWA(설치형 앱)를 거쳐 필요하면 데스크톱/모바일 앱으로 확장한다.

## 핵심 결정 요약

| 주제 | 결정 | 문서 |
|---|---|---|
| 플랫폼 | 정적 웹앱(SPA) 먼저 → PWA → 필요 시 Tauri(데스크톱)/Capacitor(모바일) | 5 |
| 기술 스택 | TypeScript + Vite + React 19. 차트는 React와 분리한 Canvas 2D 엔진 | 5 |
| 데이터 | NUBASE2020 + AME2020 원본을 빌드 스크립트로 JSON 변환해 번들에 내장 (gzip 약 130–200 KB) | 4 |
| 서버·저장 | 없음. 사용자 데이터 저장 없음 (화면 설정만 브라우저 localStorage) | 1 |
| 축 방향 | 가로 N(오른쪽으로 증가), 세로 Z(위쪽으로 증가) — 표준 Segrè 차트 배치 | 2 |
| 휠 | 휠 = 세로 스크롤, Shift+휠 = 가로 스크롤, Ctrl/⌘+휠·핀치 = 줌. 설정에서 "휠 = 줌"으로 전환 가능 | 2 |
| 드래그 | 마우스 왼쪽(또는 가운데) 버튼 드래그로 모든 방향 이동, 관성 스크롤 | 2 |
| 클릭 | 핵종 선택 → 오른쪽 정보 패널 (모바일은 하단 시트) | 2 |
| 상세도 | 줌 배율에 따른 4단계 LOD: 색만 → 핵종 이름 → +반감기 → +붕괴 모드·존재비·Jπ | 2, 3 |
| 색 | 기본은 붕괴 모드 (카를스루에 핵종도 관례: 안정 검정, β− 파랑, β+/EC 빨강, α 노랑, SF 초록) | 3 |
| 언어 | 한국어 기본, 영어 전환 | 1 |
| 배포 | GitHub Pages (정적 호스팅, 운영 비용 0) | 5 |

결정을 바꿀 때는 해당 문서와 [06-roadmap.md](06-roadmap.md)의 결정 기록(ADR)을 함께 고친다.
