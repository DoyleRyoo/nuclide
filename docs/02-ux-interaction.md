# 02. 화면 구성과 인터랙션

"지도처럼 탐색"의 동작 규칙을 수치까지 정한다. 색·글꼴·크기 같은 시각 사양은 [03-visual-design.md](03-visual-design.md)에 있다.

## 1. 화면 구성

### 1.1 데스크톱 (폭 ≥ 1200px)

```
+----------------------------------------------------------------------------------+
| [1] Nuclide Map  [Search: U-235 ...   /]         [2] [Color v] [Theme] [KO] [?]  |
| Z | (3,558 nuclides · NUBASE2020 + AME2020 · axes)            +-[6] Info panel-+ |
| 92 U +-[7] Legend---+                                         | 235U       [x] | |
|   |  | ## Stable    |                                         | Uranium-235    | |
|   |  | ## beta-  .. |                                         | Z 92  N 143    | |
|   |  +--------------+  [0] Chart canvas (full screen)         |----------------| |
| 50 Sn                                                         | Half-life      | |
|   |                                                           | Decay modes    | |
|[3]|                                    +-[8] Minimap-+ +---+  | Excited states | |
|   |                                    |   .::::::.  | | + |  | Mass & energy  | |
|   |                                    |   [=view=]  | | - |  | Source         | |
|   |                                    +-------------+ |fit|  |                | |
|   +----+----+----+----+----+----+----+---- [4] N ruler +---+  +----------------+ |
+----------------------------------------------------------------------------------+
```

| 번호 | 요소 | 위치·크기 | 우선 |
|---|---|---|---|
| 0 | 차트 캔버스 | 화면 전체. 나머지 UI는 모두 그 위에 떠 있는 카드 | P0 |
| 1 | 앱 이름 + 검색창 | 왼쪽 위. 검색창 폭 360px | 이름 P0, 검색 P1 |
| 2 | 도구 모음 | 오른쪽 위: 색상 모드, 테마, 언어, 도움말(?) | 도움말 P0, 나머지 P1 |
| 3 | Z 눈금자 | 왼쪽 가장자리, 실측 폭(03 §6.4), 세로 전체 | P0 |
| 4 | N 눈금자 | 아래쪽 가장자리, 실측 높이(03 §6.4), 가로 전체 | P0 |
| 5 | 줌 컨트롤 | 오른쪽 아래: [+] [−] [전체 보기] | P0 |
| 6 | 정보 패널 | 오른쪽, 폭 380px, 도구 모음 아래부터 하단까지 | P0 |
| 7 | 범례 | 왼쪽 위(Z 눈금자 오른쪽, 지도 정보 알약 아래), 폭 232px, 접기 가능 | P0 |
| 8 | 미니맵 | 오른쪽 아래, 줌 컨트롤 왼쪽. 200×134px | P1 |

- 범례와 미니맵은 차트 경계 상자의 **빈 모서리**에 둔다. 핵종 띠가 대각선이라 왼쪽 위(작은 N, 큰 Z)와 오른쪽 아래(큰 N, 작은 Z)는 비어 있고, 왼쪽 아래에는 가벼운 핵종이 있다. 처음 설계(둘 다 왼쪽 아래)에서는 전체 보기에서 가벼운 핵종이 가려졌다. 인쇄된 카를스루에 차트도 범례를 왼쪽 위 빈 삼각형에 둔다.
- 앱 이름과 지도 정보(핵종 수 · 출처 · 축 설명)는 칸 위에 뜨므로 카드·알약 배경을 준다. 축 설명은 태블릿·모바일에서 숨긴다(눈금자 모서리 "Z / N").
- 정보 패널이 열리면 줌 컨트롤과 미니맵은 패널 왼쪽으로 옮긴다(오른쪽 여백 = 16 + 패널 폭 380 + 16 = 412px).
- 캔버스는 패널이 열려도 크기를 바꾸지 않는다(리사이즈·재계산 방지). 대신 패널이 가리는 부분을 "가용 영역"에서 뺀다(§2.4).

### 1.2 태블릿 (768–1199px)

데스크톱과 같되 정보 패널 폭 340px, 미니맵은 숨긴다.

### 1.3 모바일 (< 768px)

```
+----------------------------------+
| [1] [Search: U-235 ...    ] [=]  |
| Z |                              |
| 92 U                             |
|   |     [0] Chart canvas         |
|   |                              |
|   | [7] Legend chip       [fit]  |
|   +----+----+-- [4] N ruler ---  |
| +==============================+ |
| |           ------             | |
| | [6] Bottom sheet: 235U   [x] | |
| |   peek auto / 50% / 92%      | |
| +==============================+ |
+----------------------------------+
```

- 위: 검색창(가로 전체) + 메뉴 버튼(≡ — 색상 모드·테마·언어·도움말).
- 줌 버튼은 숨기고(핀치 사용) [전체 보기] 버튼만 오른쪽 아래에 둔다.
- 범례는 왼쪽 아래 "범례" 칩을 누르면 위로 펼쳐진다.
- 정보 패널은 하단 시트: 살짝(기호·이름 높이 실측 + 아래 안전 영역 + 16px) / 절반(50%, 살짝 높이 이상) / 전체(92%) 세 단계. 손잡이를 끌거나 탭해 바꾼다. 탭은 0→1→2→0 순환, 끌기는 양 끝 단계에서 멈춘다.
- 눈금자: Z 폭은 두 칸 글자 실측·안팎 여백·왼쪽 안전 영역의 합, N 높이는 알약 높이 + 4px 이상에 아래 안전 영역을 더한다(03 §6.4).

## 2. 좌표계와 카메라

### 2.1 월드 좌표

- 칸 1개 = 1 단위. 핵종 (N, Z)는 x ∈ [N, N+1), y ∈ [Z, Z+1) 영역을 차지한다.
- **x = N (오른쪽으로 증가), y = Z (위쪽으로 증가)**. 화면 y축은 아래로 증가하므로 변환할 때 뒤집는다.
- 차트 경계는 데이터에서 계산한다. NUBASE2020 기준 N 0–177, Z 0–118 → 178 × 119칸.

### 2.2 카메라

카메라 = `{ cx, cy, s }`

- `cx, cy`: 캔버스 중심이 가리키는 월드 좌표
- `s`: 배율 = 칸 한 변의 CSS 픽셀 수(px/칸)

캔버스 크기 W × H(CSS px)에서:

```
screenX = (x − cx)·s + W/2          x = (screenX − W/2)/s + cx
screenY = H/2 − (y − cy)·s          y = cy − (screenY − H/2)/s
```

히트 테스트: `N = floor(x)`, `Z = floor(y)` → 격자 배열 조회 O(1).

### 2.3 카메라 연산

| 연산 | 식 |
|---|---|
| 화면 점 p를 고정한 채 k배 줌 | `w = toWorld(p)`, `s' = clamp(s·k, sMin, sMax)`, `cx' = w.x − (p.x − W/2)/s'`, `cy' = w.y + (p.y − H/2)/s'` |
| 드래그 이동 (포인터 이동량 dx, dy) | `cx −= dx/s`, `cy += dy/s` — 지도가 포인터를 따라 움직인다 |
| 휠 스크롤 (ΔX, ΔY, px 단위) | `cx += ΔX/s`, `cy −= ΔY/s` — 문서 스크롤과 같은 방향(휠을 아래로 굴리면 아래쪽, 즉 작은 Z가 보인다) |

### 2.4 가용 영역 (safe area)

캔버스에서 떠 있는 UI가 가리는 부분을 뺀 사각형이다. "전체 보기", "선택 칸 자동 이동", "버튼 줌의 기준점"을 계산할 때 쓴다.

- 기본 여백: 위는 헤더·지도 정보의 실제 하단 + 8px, 왼쪽·아래는 실측 눈금자 크기(03 §6.4), 오른쪽 16px. 데스크톱 패널이 열리면 실제 패널 왼쪽 경계에서 16px 더 띄운다.
- 모바일: 하단 시트가 열리면 실제 외곽 높이와 N 눈금자 높이 중 큰 값을 아래 여백으로 쓴다.
- 레이아웃이 바뀌면 React 쪽에서 엔진의 `setSafeInsets()`를 호출한다.

### 2.5 배율 범위

- `sFit` = 차트 전체(178 × 119칸)가 가용 영역에 들어가는 배율 = `min(가용 폭 / 178, 가용 높이 / 119)`
  - 예: 1920×1080 화면 → 약 8 px/칸, 390×844 모바일 → 약 2 px/칸
- `sMin = 0.8 × sFit`, `sMax = 256 px/칸`
- 첫 화면: `s = sFit`, 차트 중심에 맞춤

### 2.6 이동 범위 제한

카메라 중심을 차트 경계 상자에서 2칸 바깥까지로 제한한다.

`cx ∈ [Nmin − 2, Nmax + 3]`, `cy ∈ [Zmin − 2, Zmax + 3]`

어떤 배율에서도 화면 중심이 차트 근처에 있으므로 차트를 잃어버리지 않는다. 경계에 닿으면 탄성 효과 없이 멈춘다.

## 3. 줌

| 입력 | 배율 k | 기준점 | 애니메이션 |
|---|---|---|---|
| Ctrl/⌘ + 휠 | `k = 2^(−ΔY/200)`. ΔY는 px로 정규화한 뒤 이벤트당 ±100으로 제한 → 마우스 한 칸(ΔY≈100) ≈ ×1.41 | 포인터 | 없음 |
| 트랙패드 핀치 — Chrome·Edge·Firefox (`ctrlKey`가 켜진 wheel 이벤트로 들어옴) | 위와 같은 식 | 포인터 | 없음 |
| 트랙패드 핀치 — Safari (비표준 `gesturestart/gesturechange`) | `k = scale / 직전 scale` | 포인터 | 없음 |
| 터치 핀치 | `k = 현재 두 손가락 거리 / 직전 거리`, 중점이 움직인 만큼 함께 이동 | 두 손가락 중점 | 없음 |
| [+] / [−] 버튼 | ×2 / ÷2 | 가용 영역 중심 | 200 ms |
| `+` `=` / `-` 키 | ×2 / ÷2 | 선택 칸이 화면 안에 있으면 그 칸, 아니면 가용 영역 중심 | 200 ms |
| 더블클릭 / 더블탭 | ×2 | 포인터 | 250 ms |
| Shift + 더블클릭 | ÷2 | 포인터 | 250 ms |
| [전체 보기] 버튼 / `0` 키 | → `sFit` | 차트 중심 | 400 ms |

- 브라우저 페이지 확대(Ctrl+휠)는 캔버스 위에서만 막는다(wheel 리스너 `passive: false` + `preventDefault`). 키보드 Ctrl + `+`/`-`/`0`은 가로채지 않는다 — 접근성을 위해 브라우저 확대를 남겨 둔다.
- 배율이 한계에 닿으면 더 변하지 않고, 해당 줌 버튼은 비활성으로 표시한다.

## 4. 휠 스크롤

1. **정규화**: `deltaMode` 0(px)은 그대로, 1(line)은 ×20px, 2(page)는 ×(가용 높이의 90%).
2. **방향**: ΔY → 세로 이동, ΔX → 가로 이동. 1:1 픽셀 대응(휠 100px = 화면 100px 이동).
3. **Shift + 휠**: `shiftKey`이고 ΔX = 0이면 ΔY를 ΔX로 쓴다. OS·브라우저가 이미 ΔX로 바꿔 준 경우는 그대로 둔다.
4. **트랙패드 두 손가락 스크롤**: ΔX, ΔY가 함께 들어오므로 대각선 이동이 자연스럽게 된다.
5. **"휠 = 줌" 모드 (설정, P1)**: Ctrl 없는 휠도 줌으로 처리한다. Shift + 휠은 여전히 가로 스크롤.
6. 스크롤 가능한 패널·목록 위에서는 지도가 움직이지 않는다. 리스너는 캔버스 요소에만 달고, 패널에는 `overscroll-behavior: contain`을 준다.

## 5. 드래그 이동

- **Pointer Events** + `setPointerCapture`로 구현한다(포인터가 창 밖으로 나가도 계속 추적).
- 왼쪽 버튼(0) 또는 가운데 버튼(1)으로 드래그한다. 가운데 버튼의 기본 자동 스크롤은 막는다.
- 상태: `대기 → 누름 → (임계 이동 초과) 드래그 → 놓음`
  - 임계 이동: 마우스·펜 4px, 터치 8px. 넘지 않고 놓으면 **클릭**으로 처리한다.
  - 드래그 중에는 호버 강조와 툴팁을 끈다.
- 커서: 빈 곳 `grab`, 핵종 칸 위 `pointer`, 드래그 중 `grabbing`.
- **관성 (P1)**: 놓기 직전 100 ms 동안의 포인터 이동으로 속도 v₀를 추정한다.
  - |v₀| ≥ 0.2 px/ms이면 관성을 시작하고, v₀는 최대 4 px/ms로 제한한다.
  - `v(t) = v₀ · e^(−t / 325ms)`, |v| < 0.01 px/ms이면 멈춘다(총 이동 거리 ≈ v₀ × 325 ms).
  - 새 포인터 입력·휠·키 입력이 오면 즉시 멈춘다. `prefers-reduced-motion: reduce`이면 쓰지 않는다.

## 6. 선택과 호버

### 6.1 클릭/탭

- 핵종 칸 클릭 → 선택 + 정보 패널 열기. 이미 선택한 칸을 다시 클릭해도 선택을 유지한다.
- 빈 곳 클릭 → 선택 해제 + 패널 닫기(지도 앱 관례).
- 예측(미관측) 핵종도 선택할 수 있다. 패널에 "미관측 · 추정값" 배지를 붙인다.
- 선택한 칸이 가용 영역(가장자리 여백 24px 포함) 밖에 있으면, 보이게 되는 최소 거리만큼 300 ms 동안 이동한다. 패널·하단 시트가 열리거나 크기가 바뀌어 가용 영역이 줄 때도 같다(모바일에서 딥링크로 연 핵종이 시트 뒤에 숨지 않게). fly-to 중이면 그 목적지를 기준으로 고친다.

### 6.2 호버 (마우스만)

- 칸 위에 있으면 얇은 테두리를 그리고 눈금자에서 해당 Z, N을 강조한다.
- 툴팁 (P1): LOD 0–1에서만, 120 ms 머문 뒤 표시한다. 예: `²³⁵U 우라늄-235 · 704 My · α`. LOD 2 이상에서는 칸에 글자가 있으므로 띄우지 않는다.

## 7. 키보드

지도(캔버스 컨테이너)에 포커스가 있을 때:

| 키 | 동작 |
|---|---|
| ← / → | 같은 행에서 N−1 / N+1 방향으로 가장 가까운 핵종으로 선택 이동 |
| ↑ / ↓ | 같은 열에서 Z+1 / Z−1 방향으로 가장 가까운 핵종으로 선택 이동 |
| (선택 없이 방향키) | 가용 영역 중심에 가장 가까운 핵종을 선택 |
| Shift + 방향키 | 화면 이동 (가용 영역 크기의 20%) |
| `+` `=` / `-` | 줌 인 / 줌 아웃 |
| `0` | 전체 보기 |
| Enter / Space | 선택 핵종의 정보 패널 열기 |
| Esc | 검색 닫기 → 패널 닫기 → 선택 해제 (누를 때마다 한 단계) |
| `/` 또는 Ctrl/⌘ + K | 검색창으로 이동 (어디서나) |
| `c` | 색상 모드 순환 (P1) |
| `?` | 단축키 도움말 (P1) |

- 방향키로 선택이 바뀔 때 패널이 열려 있으면 내용이 바뀌고, 닫혀 있으면 닫힌 채 선택 테두리만 움직인다. 선택 칸이 화면 밖으로 나가면 카메라가 따라간다(§6.1 규칙).
- Tab 순서: 검색 → 도구 모음 → 지도 → 줌 컨트롤 → 범례 → 패널.

## 8. 줌 단계별 상세도 (LOD)

| 단계 | 배율 s (px/칸) | 칸에 그리는 것 | 그 밖 |
|---|---|---|---|
| LOD 0 | s < 32 | 색만 | 마법수 라벨("Z=50", "N=82"), 자연 존재 띠(s ≥ 8), 툴팁 사용 |
| LOD 1 | 32 ≤ s < 64 | 핵종 이름 (²³⁵U) | 이성질체 삼각형 표식 추가, 툴팁 사용 |
| LOD 2 | 64 ≤ s < 128 | 이름 + 반감기 (안정 핵종은 자연 존재비) | 붕괴 화살표에 분기비 라벨 |
| LOD 3 | s ≥ 128 | 이름 + 반감기 + 붕괴 모드 최대 2개 + Jπ + 자연 존재비 | — |

- 줌 버튼 한 번(×2)이 LOD 한 단계에 대응하도록 임계값을 2배 간격으로 잡았다.
- 깜빡임 방지: 각 임계값부터 1.15배 구간(예: 32–36.8px)에서 새로 나타나는 글자의 불투명도를 0 → 1로 보간한다.
- 칸 안 배치와 글자 크기는 [03 §5](03-visual-design.md#5-칸셀-디자인)에 있다.

## 9. 정보 패널

- 열기: 칸 클릭, Enter, 검색 결과 선택. 200 ms 슬라이드.
- 닫기: [×], Esc → 패널만 닫고 선택은 유지. 빈 곳 클릭 → 패널 닫기 + 선택 해제.
- 키보드로 열면 패널 제목으로 포커스를 옮기고, 닫으면 지도로 돌려준다.
- 스크롤은 패널 안에서만 일어난다.
- 섹션 순서: 헤더 → 기본 → 붕괴 → 들뜬 상태 → 질량·에너지(질량 초과는 P0, AME 값은 P1) → 출처. 구성과 모양은 [03 §7.6](03-visual-design.md#76-정보-패널).
- 딸핵 칩(P1): 누르면 그 핵종으로 날아가 선택한다. 딸핵이 데이터에 없으면 비활성 칩으로 표시한다.
- 이웃 이동 버튼(P1): 헤더에 `←N−1` `N+1→` `↑Z+1` `↓Z−1`. 터치 사용자를 위한 방향키 대용이다.
- 링크 복사 버튼(P1): 현재 핵종의 딥링크(§14)를 클립보드에 복사하고 토스트로 알린다.

## 10. 검색 (P1)

### 10.1 입력 문법

| 입력 예 | 해석 |
|---|---|
| `U-235`, `U235`, `u 235`, `235U`, `235-U` | 핵종 (원소 기호 + 질량수) |
| `Tc-99m`, `99mTc`, `Hf-178m2` | 핵이성질체 → 기저 칸을 선택하고 패널에서 해당 상태를 펼친다 |
| `우라늄-235`, `우라늄 235`, `uranium-235`, `Uranium235` | 원소 이름 + 질량수 |
| `U`, `우라늄`, `uranium`, `Z=92`, `z92`, `92` | 원소 → 그 원소의 동위원소 행 전체가 보이게 이동 + 행 강조 |
| `N=126`, `n126` | 동중성자핵 열 전체가 보이게 이동 + 열 강조 |
| `A=235` | 동중원소 대각선 강조 (P2) |
| `n`, `neutron`, `중성자` | 중성자 |
| `D`, `중수소`, `deuterium` / `T`, `삼중수소`, `tritium` | ²H / ³H |
| `나트륨`, `칼륨`, `요오드` … | 옛 원소 이름도 인식(→ 소듐, 포타슘, 아이오딘). 별칭 목록은 [04 §8](04-data.md#8-원소-표) |

- 정규화: 앞뒤 공백 제거, 대소문자 무시, 전각 → 반각, 하이픈·공백은 있어도 없어도 된다.
- `m`이 원소 기호의 일부인지 이성질체 표시인지 모호하면 **유효한 원소 기호 해석을 먼저** 쓴다(예: `24mg` → Mg-24, `99mtc` → Tc-99m).

### 10.2 동작

- 입력할 때마다 후보를 최대 8개 보여준다: 표기(²³⁵U) + 이름(우라늄-235) + 반감기·주 붕괴 모드 + 색 점.
- ↑↓로 후보 이동, Enter로 선택, Esc로 닫기. 후보를 고르지 않고 Enter → 첫 번째 해석 결과로 이동.
- 핵종 결과: 그 칸으로 날아가(fly-to, 목표 배율 = max(현재 배율, 96px) → LOD 2) 선택하고 패널을 연다.
- 원소·열 결과: 해당 행/열의 경계 상자가 가용 영역에 맞도록 이동하고, 1.2초 동안 두 번 깜빡이며 강조한다.
- 해석 실패: "찾을 수 없음"과 입력 예시 3개를 보여준다.

## 11. 터치 제스처

| 제스처 | 동작 |
|---|---|
| 한 손가락 드래그 | 이동 (관성 P1) |
| 두 손가락 핀치 | 중점 기준 줌 + 중점 이동만큼 이동 |
| 탭 | 선택 (더블탭을 기다리느라 늦추지 않고 즉시) |
| 더블탭 (300 ms, 24px 이내) | 탭 위치 기준 ×2 줌 |
| 두 손가락 탭 | ÷2 줌 (P2) |
| 하단 시트 끌기 | 시트 높이 단계 전환 |

- 캔버스에만 `touch-action: none`을 줘서 브라우저 기본 스크롤·확대를 막는다. 패널과 UI 영역은 기본 동작을 유지한다(페이지 확대 가능 → 접근성). 검색 입력과 select는 모든 화면 폭에서 최소 16px로 입력 포커스의 자동 확대를 방지한다. 사용자가 실행한 확대를 강제로 복원하지 않는다. 전역 핀치 차단이나 maximum-scale 제한은 추가하지 않는다. 추후 UI 핀치를 차단하려면 200% 확대 대안을 먼저 구현·검증해야 한다.

## 13. 애니메이션

| 대상 | 시간 | 이징 |
|---|---|---|
| 버튼·키 줌 | 200 ms | ease-out cubic |
| 더블클릭 줌 | 250 ms | ease-out cubic |
| 전체 보기 | 400 ms | ease-in-out cubic |
| fly-to (검색·딸핵 이동) | 300–800 ms, 거리에 비례 | ease-in-out cubic. 중심은 선형, 배율은 로그 공간에서 보간 |
| 선택 칸 자동 이동 | 300 ms | ease-out cubic |
| 패널 열기/닫기 | 200 ms | standard |

- 애니메이션 중에 사용자 입력이 오면 즉시 취소하고 입력을 따른다.
- `prefers-reduced-motion: reduce`: 카메라 애니메이션은 즉시 이동, 관성 끔, 패널은 페이드만.
- fly-to 거리가 화면 3개 이상이면 "줌 아웃 → 이동 → 줌 인" 경로(van Wijk–Nuij 방식)를 쓴다 (P2).

## 14. URL 상태 (P1)

형식: `?nuclide=U-235&color=halflife&view=143.50,92.50,64`

| 파라미터 | 값 | 비고 |
|---|---|---|
| `nuclide` | 핵종 ID (`U-235`, `Tc-99m`) | 이성질체면 기저 칸 선택 + 해당 상태 펼침 |
| `color` | `decay` \| `halflife` \| `binding` (P2: `year` \| `abundance`) | 기본값(`decay`)이면 생략 |
| `view` | `cx,cy,s` (소수 둘째 자리) | 없으면 `nuclide` 위치로(LOD 2), 둘 다 없으면 전체 보기 |

- 선택이 바뀌면 `history.pushState`(뒤로 가기 = 이전 선택), 카메라가 바뀌면 멈춘 뒤 300 ms에 `history.replaceState`.
- 잘못된 값은 조용히 무시하고 기본값을 쓴다.
- 쿼리 문자열 방식이라 서버 라우팅이 없는 정적 호스팅에서도 동작한다.

## 16. 접근성 인터랙션

- 지도 컨테이너: `tabindex="0"`, `role="application"`, `aria-roledescription="핵종 지도"`, `aria-label`에 조작 요약.
- 선택이 바뀌면 `aria-live="polite"` 영역으로 읽어 준다. 예: "우라늄-235, Z 92, N 143, 반감기 7억 400만 년, 알파 붕괴".
- 키보드로 지도에 포커스가 오면 컨테이너에 포커스 링을 그린다.
- 패널: 데스크톱은 `role="complementary"`, 모바일 하단 시트는 `role="dialog"`(포커스 관리 포함).
- 아이콘 버튼마다 `aria-label`과 툴팁(단축키 포함)을 단다.
