# R3-2 — ‘같은 출처, 다른 값’ 전수 선별 (¹³⁸Cs형 오기 찾기)

검증일: 2026-10-02. 2차에서 ¹³⁸Cs 오기는 규칙 기반 선별로는 잡히지 않고 외부 평가와 비교해서야 드러났다. 이번에는 그 유형을 바닥상태 전체에서 찾았다. 스크립트 [same_source_screen.py](evidence/same_source_screen.py), 결과 [same-source-screen.json](evidence/same-source-screen.json).

## 규칙

NUBASE2020이 어떤 값에 자체 참조(Table I 갱신 코드 T·D)도 주석도 두지 않았다면, 그 값은 Ens 연도의 ENSDF 파일을 그대로 쓴 것이다. LiveChart가 보여 주는 ENSDF 평가의 cutoff 연도가 NUBASE의 Ens 연도 이하이면 둘은 같은 평가를 본 셈이다. 이때 반올림(양쪽 마지막 자리의 절반 합)을 넘는 차이는 옮겨 적기 오류 후보다.

| 단계 | 수 |
| --- | --- |
| 앱·LiveChart 바닥상태 짝 | 3,357 |
| 같은 평가를 본 짝 (LiveChart cutoff 연도 ≤ NUBASE Ens 연도) | 2,803 |
| 비교한 반감기 (NUBASE 자체 근거 없음, 값형, 폭 아님) | 1,417 |
| 비교한 분기비 (NUBASE `=` 값, LiveChart 불확도 있음) | 497 |
| 후보 | 반감기 17, 분기비 8 |

분기비는 LiveChart 불확도가 있는 값만 비교했다. API가 부등호를 버리므로 불확도 없는 값은 한계값일 수 있다(2차 02). NUBASE의 `B+`(EC+e⁺ 합계)는 LiveChart의 `B+`(양전자 몫)가 아니라 NUBASE `e+`와 짝지었다.

## 결과

**새 원문 오기는 찾지 못했다.** 선별은 2차의 알려진 사례 6건(¹³⁸Cs, ¹⁸⁸Pb, ⁹³Rh, ¹⁵¹Ho, ¹⁶⁴Ho, ¹⁸²Pt)을 모두 다시 찾아 규칙이 유효함을 보였다. 나머지 후보는 아래처럼 설명된다. [확인됨: NNDC 문서 [nndc/](evidence/nndc/)]

| 분류 | 건수 | 핵종 | 설명 |
| --- | --- | --- | --- |
| 2차에서 이미 판정 | 반감기 3, 분기 3 | ¹³⁸Cs(E), ¹⁸⁸Pb·⁹³Rh(C) / ¹⁵¹Ho·¹⁶⁴Ho·¹⁸²Pt(E) | 2차 02·03 문서 |
| 바닥·이성질체 배정 차이 | 반감기 7 | ¹¹⁹Ag, ¹²⁴La, ¹³⁸Pm, ¹⁷²Re, ¹⁸⁴Bi, ¹⁹²At, ²⁵⁶Es | LiveChart 바닥상태 값이 NUBASE 이성질체 반감기와 같다. 상태 배정의 차이다 |
| 참조 쪽 구판 | 분기 1 | ⁷⁶Sr | 아래 |
| 작은 차이 (z < 1.5) | 반감기 7, 분기 4 | ³³Na, ³³Si, ⁶⁶Co, ⁷⁹Ni, ¹⁰⁸Zr, ¹⁶³W, ²⁵⁸Md / ¹⁷C, ¹⁴⁶Pm, ²⁰⁴At(2행) | NUBASE 자체 평균·반올림으로 설명 가능한 크기 |

### ⁷⁶Sr β⁺지연 양성자 — 앱이 맞다

- 앱·NUBASE2020: `β+p 3.4×10⁻³ %` (원문 `B+p=3.4e-3 8`).
- LiveChart 스냅샷: `ECP 0.000034 %` (2011 평가). 정확히 100배 차이다.
- NuDat 현재 ENSDF (Singh, Chen, Farhan, Nucl. Data Sheets 194, 3 (2024), cutoff 2024-01-08): **%εp = 3.4E−3 (8)**. [문서](evidence/nndc/76sr_adopted.html)
- 판정: 2011 평가의 값이 분율과 퍼센트를 혼동한 것으로 보이며 2024 평가에서 바로잡혔다. 앱 값이 맞다. [확인됨: 2024 ENSDF / 추정: 2011 값의 원인]

### 작은 차이의 예

- ¹⁶³W: ENSDF 2.67(10) s는 측정 4개의 가중평균(2.6(1), 3.0(13), 3.0(2), 2.5(3) s). NUBASE 2.63(9) s는 같은 자료를 다르게 묶은 값으로 보인다.
- ⁶⁶Co: ENSDF 0.20(2) s는 측정 4개의 가중평균. NUBASE 194(17) ms.
- ²⁰⁴At: ENSDF %ε 96.09(16), %α 3.91(16). NUBASE 96.2(2) / 3.8(2).

이들은 차이가 불확도보다 작고 측정값 목록 안에서 설명된다. 오기로 분류하지 않았다.

## LiveChart 스냅샷의 지연

NuDat은 이미 더 새로운 ENSDF 평가를 보여 주는데 LiveChart API 스냅샷(2026-10-01)은 이전 평가를 준 경우가 있다.

| 핵종 | LiveChart 스냅샷 평가 | NuDat 현재 평가 |
| --- | --- | --- |
| ⁷⁶Sr | 2011 | Nucl. Data Sheets 194, 3 (2024) |
| ³³Na, ³³Si | 2011 | Nucl. Data Sheets 199, 1 (2025) |
| ²²⁹Am (2차) | 2015 | Nucl. Data Sheets 208, 397 (2026) |

비교 도구가 LiveChart만 기준으로 삼으면 이미 고쳐진 값과 비교하게 될 수 있다. 차이가 나면 NuDat의 현재 평가로 한 번 더 확인하는 단계를 제안한다(적용하지 않음).

## 한계

- 바닥상태만, NUBASE가 자체 근거를 밝히지 않은 값만 대상이다. NUBASE가 참조를 달고도 잘못 적은 경우는 이 규칙으로 잡히지 않는다.
- Ens 연도 비교는 연 단위다. 같은 해의 다른 ENSDF 개정본이 섞였을 가능성은 남는다.
- z < 1.5 후보 11건은 개별 원 논문을 확인하지 않았다.
