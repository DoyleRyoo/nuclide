# R3-1 — 독립 파서로 전 상태 재대조

검증일: 2026-10-02. 2차는 자동 플래그 318건만 원문과 대조했다. 이번에는 NUBASE2020 원문의 **모든 상태**를 앱과 독립된 고정 열 파서로 다시 읽어, 앱이 원문에서 가져오는 필드 전부를 비교했다. 스크립트 [full_reparse.py](evidence/full_reparse.py), 결과 [full-reparse.json](evidence/full-reparse.json).

## 딸 상태 feeding 주석 — 1차 기록 정정

NUBASE 원문 11개 붕괴에는 딸핵종의 바닥상태·이성질체로 가는 비율이 `[gs=…,m=…]`로 붙어 있다(예: ²⁴Ne `B-=100[gs=0,m=100]`, ⁷⁷Ga `B-=100[gs=12,m=88]`, ¹¹⁴Inᵐ² `IT=100[gs=0,m=100]`).

- 앱 파서는 이를 `note`로 보존한다(`scripts/build-data/decayModes.ts:28-67`, `parsers.test.ts:20-36`).
- 상세 패널은 `β− 100 % → 24Na [gs=0,m=100]`처럼 **원문 표기 그대로** 보여 준다. [화면](evidence/ui/ui-Ne-24.png), [⁷⁷Ga](evidence/ui/ui-Ga-77.txt), [¹¹⁴Inᵐ²](evidence/ui/ui-In-114m2.txt), [¹¹⁸Inᵐ²](evidence/ui/ui-In-118m2.txt)
- 비교용 내보내기(`tools/livechart-diff/export_nuclides.ts`)에는 이 필드가 없어, 처음 대조에서는 “손실”로 잘못 셌다. 화면과 코드로 확인해 바로잡았다.

1차 1단계 B-2의 “딸 상태/준위·feeding intensity는 저장하지 않음”은 이 11건에 한해 정확하지 않다. 1차 SCI-04(딸 상태 식별 부재)는 원문에 이런 주석이 없는 일반적인 경우(예: ¹³⁷Cs → ¹³⁷ᵐBa)에 그대로 유효하다.

남는 표시 문제(낮음, [교육][방사화학]): 주석이 해설 없이 원문 기호 그대로이고, 딸 링크는 여전히 바닥상태(`→ 24Na`)를 가리킨다. ²⁴Ne는 100 %가 ²⁴Naᵐ으로 간다고 주석이 말하는데 링크는 ²⁴Na 바닥상태로 간다. 개선 제안(적용하지 않음): 주석을 “딸 바닥상태 0 %, 이성질체 100 %”처럼 풀어 쓰고, 해당 이성질체로 연결한다.
