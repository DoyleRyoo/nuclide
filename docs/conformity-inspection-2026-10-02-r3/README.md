## 2차까지의 판단에서 바뀐 것

- 1차 1단계 B-2 “딸 상태/준위·feeding intensity는 저장하지 않음”: 원문 주석이 있는 11개 붕괴에 한해 정정. 앱은 `[gs=…,m=…]`를 보존해 패널에 보여 준다.
- 2차 B 분류: ²⁵²Lr은 ENSDF 계산값(CA)이라 정책 차이(P)에 가깝다.
- 원문 오기 목록(2차 03)에 추가할 항목은 바닥상태 선별에서 나오지 않았다. 이성질체에서는 ¹³⁸Prᵐ(2017 평가 미반영)이 ¹³⁸Cs와 같은 A = 138 사슬 문제로 더해졌다.
- 외부 DB도 틀린다: ⁷⁶Sr(2011 ENSDF ×100), ⁶⁴Mnᵐ·²¹³Pbᵐ(ENSDF 단위). 앱 값을 외부 값으로 일괄 덮어쓰면 안 된다.
