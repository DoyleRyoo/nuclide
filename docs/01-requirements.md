# 01. 요구사항 정의

## 1. 배경과 목표

핵종도(Table/Chart of Nuclides)는 모든 원자핵 종류를 N–Z 평면에 칸으로 배치한 표다. 칸이 3,000개가 넘어 한 화면에 읽을 수 있는 크기로 담을 수 없으므로, **지도처럼 확대할수록 정보가 늘어나는 방식**으로 보여준다.

**목표**

1. 관측된 모든 핵종을 하나로 이어진 "지도"로 보여준다.
2. 지도 앱 수준의 탐색(줌, 휠 스크롤, 드래그 이동)을 제공한다.
3. 핵종을 클릭하면 평가 데이터(evaluated data)를 원문 정밀도 그대로 보여준다.
4. 서버 없이 동작하고, 한 번 방문하면 오프라인에서도 동작한다.

**성공 기준 (v1.0)**

- NUBASE2020의 관측 기저 상태 3,340개가 모두 표시되고, 표시 값이 원본과 일치한다(빌드 시 자동 검증).
- d.md의 인터랙션 5가지(줌 인, 줌 아웃, 가로/세로 휠 스크롤, 4방향 드래그 이동, 클릭 시 정보)가 데스크톱과 모바일에서 동작한다.
- 데스크톱에서 이동·확대 중 60fps를 유지한다.

## 2. 대상 사용자

| 사용자 | 주요 목적 | 설계에 주는 영향 |
|---|---|---|
| 학생·교사 (고교~학부) | 핵종도 구조 이해, 안정성 계곡·마법수 관찰 | 범례, 한국어 용어, 첫 방문 안내, 읽기 쉬운 반감기 환산 |
| 연구자·엔지니어 | 반감기·분기비·Q값 빠른 확인 | 검색, 원문 정밀도·불확도 표시, 키보드 조작, 딥링크 |
| 일반 관심층 | 둘러보기 | 부드러운 지도 조작, 모바일 지원 |

## 3. 범위

**포함 (v1)**: 웹앱, 핵종 차트 시각화, 핵종 상세 정보, 검색, 딥링크, 한/영 UI, 라이트/다크 테마, PWA 오프라인.

**제외 (v1)** — 필요해지면 로드맵에서 다시 검토한다.

- 서버, DB, 계정, 사용자 데이터 저장·동기화 (d.md: "사용자의 데이터를 저장할 필요도 없으니")
- 실행 중 외부 API 호출 (데이터는 전부 내장)
- 감마선 에너지·준위도 같은 ENSDF 수준의 상세 준위 데이터, 핵반응 단면적, 핵분열 수율
- 데이터 편집, 사용자 메모·즐겨찾기
- 인쇄용 포스터 출력
- 앱스토어 배포 (v1 이후 검토)

## 7. 제약과 가정

- 핵 데이터 평가본(AME/NUBASE)은 약 4년 주기(2003, 2012, 2016, 2020)로 나오므로 **데이터를 앱에 내장**하는 것이 합리적이다(d.md의 판단과 같다). 데이터 갱신은 앱 재배포로 한다.
- 1인 개발, 정적 호스팅, 운영 비용 0을 전제로 한다.
- 사용자 데이터를 받지 않으므로 개인정보 처리 절차가 필요 없다.

## 8. 용어

| 용어 | 뜻 |
|---|---|
| 핵종 (nuclide) | 양성자 수 Z와 중성자 수 N(그리고 에너지 상태)으로 구분되는 원자핵의 종류 |
| 동위원소 (isotope) | Z가 같은 핵종들 — 차트의 같은 행 |
| 동중성자핵 (isotone) | N이 같은 핵종들 — 같은 열 |
| 동중원소 (isobar) | A = Z + N이 같은 핵종들 — 대각선 |
| 기저 상태 (ground state) | 가장 낮은 에너지 상태. 차트의 칸 하나 = 기저 상태 하나 |
| 핵이성질체 (nuclear isomer) | 수명이 긴 들뜬 상태(예: ⁹⁹ᵐTc) |
| 반감기 (T½) | 절반이 붕괴하는 데 걸리는 시간 |
| 분기비 (branching ratio) | 여러 붕괴 모드 각각이 차지하는 비율(%) |
| 질량 초과 (mass excess, Δ) | (원자 질량 − A × 1 u)를 에너지(keV)로 나타낸 값 |
| Q값 | 붕괴·반응에서 나오는 에너지 |
| 분리 에너지 (Sn, Sp) | 중성자/양성자 하나를 떼어내는 데 필요한 에너지 |
| 마법수 (magic number) | 핵이 특히 안정한 Z 또는 N 값: 2, 8, 20, 28, 50, 82, 126 |
| 계통성 추정값 (`#`) | 실험값이 아니라 주변 핵종의 경향으로 추정한 값 (NUBASE/AME의 `#` 표기) |
| IAS | 동위스핀 유사 상태(isobaric analog state). 이 앱에서는 표시하지 않는다 |
| LOD | Level of Detail. 줌 배율에 따라 칸에 그리는 정보의 양 |
| 월드 좌표 | 칸 1개 = 1 단위인 차트 좌표 (x = N, y = Z) |
| 카메라 | 화면 중심의 월드 좌표와 배율(칸당 픽셀)의 묶음 |
